# 문제 정의

participant에 있는 이름과 completion에 있는 이름의 개수가 맞아야 한다. 
동명이인이 있어서, 중복처리를 해서는 안되고 같은 이름의 개수를 카운팅 해줘야 한다. 
<br>

# 코드로 문제 풀이

    String answer = "";
    
    HashMap<String,Integer> map = new HashMap<>();
    HashMap<String,Integer> comMap = new HashMap<>();
    
    for(int i =0; i<participant.length; i++){
        if(map.containsKey(participant[i])){
            //동명이인 처리
            int base= map.get(participant[i]);
            map.put(participant[i],base+1);
            continue;
        }
        map.put(participant[i],1);
    }
    
    for(int i =0; i<completion.length; i++){
        if(comMap.containsKey(completion[i])){
            //동명이인 처리
            int base= map.get(completion[i]);
            comMap.put(completion[i],base+1);
            continue;
            
        }
        comMap.put(completion[i],1);
    }
    for (String key : map.keySet()) {
        // 2) 이름은 있는데, 인원수(value)가 다른 경우 (동명이인 중 미완주자)
        if (!map.get(key).equals(comMap.get(key))) {
            return key;
        }
        // 1) comMap에 이름(key)이 아예 없는 경우
        if (!comMap.containsKey(key)) {
            return key;
        }
        
    }

> 수정할 부분
 
길게 늘어진 조건문과 반복적으로 사용되는 로직으로 인한 가독성이 떨어지고 코드를 작성하거나 수정할때 실수가 벌어질 가능성이 높다. 

# 수정된 코드

String answer = "";

    HashMap<String,Integer> map = new HashMap<>();
    HashMap<String,Integer> comMap = new HashMap<>();

    
    // 1. 참여자 명수 세기
    for (String p : participant) {
        map.put(p, map.getOrDefault(p, 0) + 1);
    }

    // 2. 완주자 명수 세기
    for (String c : completion) {
        comMap.put(c, comMap.getOrDefault(c, 0) + 1);
    }

    // 3. 비교하기
    for (String key : map.keySet()) {
        // 완주자 명단에 없거나, 이름은 있는데 인원수가 맞지 않는 경우
        if (!comMap.containsKey(key) || !map.get(key).equals(comMap.get(key))) {
            return key;
        }
    }
    return answer;

> 코드 논리
1. 참여자 명단을 순회하며 (이름, 빈도수)를 Map A에 기록한다.

2. 완주자 명단을 순회하며 (이름, 빈도수)를 Map B에 기록한다.

3. Map A의 모든 열쇠(이름)를 하나씩 꺼내며 검사한다.

4. 조건 1: 이름이 Map B(완주자)에 있는가? (없으면 미완주자)

5. 조건 2: 이름이 있다면, Map A의 숫자와 Map B의 숫자가 일치하는가? (다르면 동명이인 중 미완주자)

- getOrDefault 를 사용해서 불필요한 조건 사용을 줄였다.
