# 문제 정의

* 이진 트리 모양 초원의 각 노드에 양과 늑대가 배치되어 있으며, 루트 노드에서 출발하여 양을 최대한 많이 모으는 규칙을 파악 
* 노드를 방문할 때마다 해당 노드의 동물들이 따라오며, 늑대의 수가 양의 수 이상이 되는 순간 모든 양을 잡아먹히므로 이를 방지하는 조건을 확인 

---

# 제약 조건 분석

* 노드의 최대 개수가 17개 이하로 매우 작기 때문에, 모든 가능한 방문 경로를 탐색하는 완전탐색 및 깊이 우선 탐색 방식의 적용이 가능함을 확인
* 0번 노드는 항상 양이 위치한 루트 노드이며, 부모와 자식 간의 간선 정보가 주어지므로 트리 구조를 추적할 수 있음을 파악 

---

# 패턴 단순화 및 추상화

* 일반적인 트리 순회와 달리, 방문한 노드의 자식 노드뿐만 아니라 이미 방문한 노드들과 연결되어 아직 방문하지 않은 모든 자식 노드들을 다음 탐색 후보로 확장할 수 있음을 확인
* 현재까지 방문한 노드들의 집합과 다음에 방문할 수 있는 후보 노드 목록을 상태로 유지하면서, 깊이 우선 탐색을 통해 모든 유효한 경로를 탐색하도록 설계 

---

# 경계 조건

* 현재 탐색 중인 노드를 방문했을 때 늑대의 수가 양의 수와 같거나 많아지는 경우, 즉시 해당 경로의 탐색을 중단하여 불필요한 연산을 방지하도록 설정 
* 매 순간 모은 양의 수를 최댓값과 비교하여 갱신하고, 더 이상 유효한 다음 노드가 없거나 조건에 어긋날 때 안전하게 종료되도록 관리 

---

# 최적의 알고리즘

1. 0번 루트 노드에서 시작하여 현재 방문한 노드가 양인지 늑대인지 판별하고 누적 개수를 갱신 
2. 갱신된 상태에서 늑대의 수가 양의 수 이상인지 검사하여 조건 위반 시 탐색을 즉시 종료하고 백트래킹 수행 확인
3. 현재까지 모은 양의 수의 최댓값을 전역 변수에 비교하여 갱신하고 최고 기록을 유지 
4. 현재 노드를 방문 가능한 다음 후보 목록에서 제거하고 이 노드와 직접 연결된 자식 노드들을 후보 목록에 새로 추가하여 탐색 범위 확장 
5. 확장된 후보 목록에 포함된 각 노드들을 다음 방문 대상으로 지정하여 깊이 우선 탐색 재귀 함수를 반복 호출하고 모든 경우의 수를 탐색 완료

# 코드

    import java.util.*;

    class Solution {
        int maxSheep = 0;
        int[] infoData;
        int[][] edgeData;

        public int solution(int[] info, int[][] edges) {
            infoData = info;
            edgeData = edges;
            
            List<Integer> nextNodes = new ArrayList<>();
            nextNodes.add(0);
            
            dfs(0, 0, 0, nextNodes);
            
            return maxSheep;
        }

        private void dfs(int current, int sheep, int wolves, List<Integer> nextNodes) {
            if (infoData[current] == 0) {
                sheep++;
            } else {
                wolves++;
            }

            if (wolves >= sheep) {
                return;
            }

            maxSheep = Math.max(maxSheep, sheep);

            List<Integer> nextList = new ArrayList<>(nextNodes);
            nextList.remove(Integer.valueOf(current));

            for (int[] edge : edgeData) {
                if (edge[0] == current && !nextList.contains(edge[1])) {
                    nextList.add(edge[1]);
                }
            }

            for (int next : nextList) {
                dfs(next, sheep, wolves, nextList);
            }
        }
    }
