# 문제 Definition

---

### 제약 조건 분석

* 문자열 길이 2,500 이하인 자연수
* 문자열 길이 N 기준 시간 복잡도 O(N^2) 이하 알고리즘 설계 필요


---

### 패턴 단순화 및 추상화

* 팰린드롬 길이가 홀수인 경우 중심점 1개 설정
* 팰린드롬 길이가 짝수인 경우 중심점 2개 설정
* 양끝 문자가 동일할 때까지 확장하여 최장 길이 갱신
* 전체 문자열 순회하며 최대 팰린드롬 길이 탐색 진행

---

### 경계 조건

* 문자열 길이가 1인 경우 최대 길이는 1로 처리
* 전체 문자열이 팰린드롬인 경우 문자열 전체 길이 반환
* 팰린드롬이 존재하지 않는 경우 최소 길이 1 반환

---

### 최적의 알고리즘

1. 문자열 길이 1 이하일 경우 해당 길이 즉시 반환
2. 문자열 인덱스 0부터 끝까지 순회 진행
3. 각 인덱스 기준 홀수 길이 팰린드롬 탐색 진행
4. 각 인덱스 기준 짝수 길이 팰린드롬 탐색 진행
5. 확장 가능 여부 확인 후 최대 길이 갱신
6. 모든 위치 탐색 종료 후 최종 구해진 최대 길이 반환

---

# 코드

    class Solution {
        public int solution(String s) {
            if (s.length() < 2) {
                return s.length();
            }

            int maxLength = 1;

            for (int i = 0; i < s.length() - 1; i++) {
                int len1 = expand(s, i, i);
                int len2 = expand(s, i, i + 1);
                int currentMax = Math.max(len1, len2);

                maxLength = Math.max(maxLength, currentMax);
            }

            return maxLength;
        }

        private int expand(String s, int left, int right) {
            while (left >= 0 && right < s.length() && s.charAt(left) == s.charAt(right)) {
                left--;
                right++;
            }
            return right - left - 1;
        }
    }
