# 문제 정의


- 맨 처음 시작은 "ICN" 로 시작, 현재위치와 방문한 여행경로에 넣어주면서면서 탐색을 시작한다.
- 해당 티켓이 사용이 됐는지, 그리고 현재 위치랑 다음 가야할 곳의 출발지를 비교하여 탐색을 하여 depth가 티켓의 수가 같아지면 해당 여행경로를 ArrayList에 담아준다.
- 탐색이 끝나면 list에는 모든 여행경로가 담겨져 있다. 리스트를 정렬을 하면 알파벳 순서가 앞서는 경로가 인덱스 0번째에 위치하게 되고, 해당 인덱스의 여행경로를 배열로 담아 리턴한다.


# 코드

    import java.util.*;

    class Solution {

        static ArrayList<String> list = new ArrayList<>();
        static boolean useTickets[];

        public String[] solution(String[][] tickets) {
            useTickets = new boolean[tickets.length];

            dfs(0, "ICN", "ICN", tickets);

            Collections.sort(list);

            return list.get(0).split(" ");
        }

        static void dfs(int depth, String now, String path, String[][] tickets){
            if (depth == tickets.length) {
                list.add(path);
                return;
            }

            for (int i = 0; i < useTickets.length; i++) {
                if (!useTickets[i] && now.equals(tickets[i][0])) {
                    useTickets[i] = true;
                    dfs(depth+1, tickets[i][1], path + " " +tickets[i][1], tickets);
                    useTickets[i] = false;
                }
            }
        }
    }


1. 모든 여행지를 만든다. 이 여행지를 나중에 알파벳 순서가 앞서는 경로를 반환해야한다(ArrayList<String> 을 만들어서 경로를 담는다.)
2.  해당 티켓을 사용했는지 안했는지 판단하는 Boolean 배열 구현
3. DFS 탐색을 통하여 모든 여행지를 만든다. depth, 현재 위치, 방문한 여행 경로, 문제에 주어진 tickets배열을 매개변수로 잡는다.
