# 문제 정의

---

### 제약 조건 분석

* 각 차량의 진입 지점과 진출 지점은 마이너스 삼만 이상 삼만 이하
* 차량이 진입하거나 진출하는 지점에 설치된 카메라도 만난 것으로 인정
* 모든 차량의 경로가 주어질 때 최소한의 카메라 개수를 반환

---

### 패턴 단순화 및 추상화


* 고속도로를 이동하는 모든 차량이 단속용 카메라를 최소 한 번은 지나치도록 설치
* 최소한의 카메라를 사용하여 모든 차량의 경로를 커버하는 지점을 결정
* 차량이 고속도로를 나가는 지점에 카메라를 설치하면 뒤따라오는 차량 중 일부를 동시에 단속 가능함
* 이전 카메라 위치보다 늦게 진입한 차량이 등장하면 새로운 카메라를 해당 차량의 진출 지점에 추가로 설치

---

### 경계 조건

* 차량 경로의 진입 지점이 진출 지점보다 크게 입력되지 않는다고 가정
* 음수 좌표 구간에서도 동일한 위치 비교 로직이 정확히 동작
* 진입 지점과 진출 지점이 동일한 차량도 정확히 카메라에 포함

---

### 최적의 알고리즘

1. 차량의 진출 지점을 기준으로 경로 배열을 오름차순 정렬
2. 첫 번째 차량의 진출 지점에 첫 번째 카메라를 설치
3. 카메라의 설치 위치를 기록하는 변수를 해당 지점으로 설정
4. 배열의 다음 차량부터 순회하며 진입 지점이 현재 카메라 위치보다 뒤에 있는지 확인
5. 진입 지점이 현재 카메라 위치보다 뒤에 있다면 새로운 카메라를 해당 차량의 진출 지점에 설치하고 카메라 개수를 늘림
6. 모든 차량을 확인한 후 최종 설치된 카메라의 총개수를 반환

---

# 코드

    import java.util.*;

    class Solution {
        public int solution(int[][] routes) {
            Arrays.sort(routes, new Comparator<int[]>() {
                @Override
                public int compare(int[] o1, int[] o2) {
                    return Integer.compare(o1[1], o2[1]);
                }
            });

            int count = 0;
            int lastCamera = -30001;

            for (int[] route : routes) {
                if (lastCamera < route[0]) {
                    count++;
                    lastCamera = route[1];
                }
            }

            return count;
        }
    }
