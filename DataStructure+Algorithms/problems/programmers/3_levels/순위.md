# 문제 정의

### 제약 조건 분석

100명으로 매우 작다. 경기 결과 수도 최대 4,500개로 적어서 O(N^3) ->시간 초과 없이 충분히 해결할 수 있다.

---

### 패턴 단순화 및 추상화

- A가 B를 이기고 B가 C를 이겼다면 -> A가 C를 이김 (승리 관계 전달)
- A가 B에게 지고 B가 C에게 졌다면 -> A가 C에게 짐 (패배 관계 전달)

---

### 경계 조건

**자기 자신과의 관계:** 자기 자신과의 승패 관계는 고려하지 않는다.
**정보 불충분:** 다른 선수와의 승패 관계를 하나라도 알 수 없다면 해당 선수의 정확한 순위는 알 수 없다.

---

### 최적의 알고리즘 
1. N \times N 크기의 승패 관계 배열을 만들고, 경기 결과에 따라 이긴 관계와 진 관계를 기록한다.
2. 거쳐가는 선수 K를 기준으로, 모든 선수 A와 B에 대해 승패 관계를 갱신한다.
3. A가 K를 이기고 K가 B를 이겼다면 A가 B를 이긴 것으로 처리한다.

4. 각 선수마다 자신을 제외한 다른 선수들과의 승패 관계(승리 또는 패배)가 총 N-1개 존재하는지 확인한다.
5. 조건 만족 시 확정 가능한 선수의 수를 1씩 증가시키고 총합을 반환한다.


# 코드

    class Solution {
        public int solution(int n, int[][] results) {
            // graph[i][j] : i번 선수가 j번 선수를 이겼으면 true
            boolean[][] graph = new boolean[n + 1][n + 1];

            // 경기 결과를 바탕으로 직접적인 승패 정보 기록
            for (int[] result : results) {
                int winner = result[0];
                int loser = result[1];
                graph[winner][loser] = true;
            }

            
            // 거쳐가는 선수 K
            for (int k = 1; k <= n; k++) {
                // 승리하는 선수 A
                for (int a = 1; a <= n; a++) {
                    // 패배하는 선수 B
                    for (int b = 1; b <= n; b++) {
                        // A가 K를 이기고 K가 B를 이겼다면, A는 B를 이김
                        if (graph[a][k] && graph[k][b]) {
                            graph[a][b] = true;
                        }
                    }
                }
            }

            //  각 선수별로 모든 선수와의 승패 관계가 확정되었는지 확인
            int answer = 0;
            for (int i = 1; i <= n; i++) {
                int count = 0; // i번 선수가 승패를 알 수 있는 상대 선수의 수
                
                for (int j = 1; j <= n; j++) {
                    if (i == j) continue; // 자기 자신과의 관계는 제외

                    // i가 j를 이겼거나, j가 i를 이겼다면 승패 관계를 아는 것
                    if (graph[i][j] || graph[j][i]) {
                        count++;
                    }
                }

                // 자신을 제외한 N-1명과의 승패 관계를 모두 안다면 순위 확정
                if (count == n - 1) {
                    answer++;
                }
            }

            return answer;
        }
    }
