
# 문제 정의 및 제약 조건 분석

* 그래프 연결 요소 탐색: 컴퓨터 간의 직접 또는 간접 연결 관계를 파악하여 독립된 네트워크의 개수 구하기
* 컴퓨터 수 및 표현 제약: 컴퓨터의 개수는 1 이상 200 이하이며, 각 컴퓨터는 0부터 n-1까지의 번호로 표현
* 연결 정보 표현: 2차원 배열에서 i번 컴퓨터와 j번 컴퓨터가 연결되어 있으면 1로 표현되며, 자기 자신과의 연결은 항상 1

# 패턴 단순화 및 추상화

* 방문 체크를 통한 중복 탐색 방지: 이미 방문한 컴퓨터는 다시 탐색하지 않도록 방문 배열을 활용하여 네트워크 단위로 묶기
* 그래프 순회 적용: 특정 컴퓨터에서 출발하여 연결된 모든 컴퓨터를 순회하며 하나의 네트워크로 카운트
* 전체 탐색 루프: 0부터 n-1까지의 컴퓨터를 순회하며, 아직 방문하지 않은 컴퓨터를 발견할 때마다 네트워크 개수를 증가시키고 해당 컴퓨터와 연결된 모든 노드 탐색

# 경계 조건

* 컴퓨터 개수 최소 및 최대: 컴퓨터가 1개뿐인 경우, 독립된 네트워크 1개로 올바르게 처리
* 모든 컴퓨터가 독립된 경우: 모든 컴퓨터 간에 연결이 전혀 없는 경우, 컴퓨터 개수만큼의 네트워크 개수 반환
* 모든 컴퓨터가 하나의 네트워크로 연결된 경우: 모든 컴퓨터가 상호 연결된 경우, 네트워크 개수 1개로 정상 처리

# 알고리즘 

1. visited는 노드 방문 여부를 체크하는 boolean형 배열을 만든다.
2. for 반복문을 통해 모든 노드를 탐색
3. 방문하지 않은 노드일 경우에는 dfs 메소드로 넘어감
4. visited를 true로 설정해준 후 네트워크 연결 정보가 담긴 computers 배열을 탐색
5. 방문한 적 없는 노드이면서 computers 배열 값이 1이라 연결되어 있다면 dfs 메소드로 넘어간다
6. 해당 로직을 통해 네트워크 개수를 answer++을 통해 파악할 수 있다.


# 코드

    class Solution {
        
        static boolean[] visited;
        
        public int solution(int n, int[][] computers) {
            int answer = 0;
            
            visited = new boolean[n];
            
            for(int i=0; i<n; i++){
                if(!visited[i]){
                    answer++;
                    dfs(i, computers);
                }
            }
            return answer;
        }
        
        public void dfs(int x, int[][] arr){
            visited[x] = true;
            for(int i=0; i<arr.length; i++){
                if(!visited[i] && arr[x][i] == 1){
                    dfs(i, arr);
                }
            }
        }
    }
