# 문제 정의

### 제약 조건 분석

* 자물쇠의 크기는 최대 이십 이하의 정사각 격자이며 열쇠 역시 크기가 작아 완전탐색 적용이 가능함을 확인
* 열쇠가 자물쇠 영역을 벗어나는 위치까지 포함하여 모든 이동 경우의 수를 고려해야 하는 구조

---

### 패턴 단순화 및 추상화

* 자물쇠의 크기를 상하좌우로 확장하여 세 배 크기의 새로운 판을 구성하고 열쇠를 그 위에서 이동시키는 방식을 도출
* 열쇠를 총 네 번 회전시키는 과정과 확장된 격자의 모든 좌표를 순회하는 반복 구조를 설정

---

### 경계 조건

* 열쇠의 돌기와 자물쇠의 돌기가 서로 겹치거나 자물쇠의 홈이 완전히 채워지지 않는 경우를 예외로 처리
* 자물쇠의 원래 영역 내부에서 모든 홈 값이 정확히 일치하는지 검사하는 조건을 확인

---

### 최적의 알고리즘 상세 설계

1. 확장 판 생성 및 중앙 배치 과정(기존 자물쇠가 확장 판의 정확한 중앙에 위치하도록 오프셋 값을 계산하여 배치)
2. 열쇠 사방 회전 반복 과정
3. 열쇠 완전탐색 이동 좌표 순회 과정(중첩 반복문을 활용하여 열쇠의 좌측 상단 모서리가 위치할 수 있는 모든 좌표 조합을 탐색)
4. 자물쇠 일치 여부 검증 및 판정 과정(모든 홈이 빈틈없이 채워져 최종 합이 모두 일로 확인되면 참을 반환하고 전체 탐색을 종료)

# 코드

    class Solution {
        public boolean solution(int[][] key, int[][] lock) {
            int n = lock.length;
            int m = key.length;
            
            int boardSize = n + m * 2 - 2;
            int[][] board = new int[boardSize][boardSize];
            
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    board[i + m - 1][j + m - 1] = lock[i][j];
                }
            }
            
            for (int r = 0; r < 4; r++) {
                key = rotate(key);
                for (int x = 0; x < n + m - 1; x++) {
                    for (int y = 0; y < n + m - 1; y++) {
                        if (check(board, key, x, y, n, m)) {
                            return true;
                        }
                    }
                }
            }
            
            return false;
        }
        
        private int[][] rotate(int[][] key) {
            int m = key.length;
            int[][] ret = new int[m][m];
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < m; j++) {
                    ret[j][m - 1 - i] = key[i][j];
                }
            }
            return ret;
        }
        
        private boolean check(int[][] board, int[][] key, int startX, int startY, int n, int m) {
            int boardSize = board.length;
            int[][] tempBoard = new int[boardSize][boardSize];
            for (int i = 0; i < boardSize; i++) {
                System.arraycopy(board[i], 0, tempBoard[i], 0, boardSize);
            }
            
            for (int i = 0; i < m; i++) {
                for (int j = 0; j < m; j++) {
                    tempBoard[startX + i][startY + j] += key[i][j];
                }
            }
            
            for (int i = 0; i < n; i++) {
                for (int j = 0; j < n; j++) {
                    if (tempBoard[i + m - 1][j + m - 1] != 1) {
                        return false;
                    }
                }
            }
            return true;
        }
    }
