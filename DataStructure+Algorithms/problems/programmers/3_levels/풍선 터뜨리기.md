# 문제 정의

이번 문제의 핵심은 '남기고 싶은 풍선보다 더 작은 값이 해당 풍선의 왼쪽, 오른쪽에 존재하는지' 파악하는 것이다.

1. 해당 풍선의 왼쪽에 해당 풍선보다 작은 값이 존재하지 않는다면, 왼쪽의 풍선들은 모두 해당 풍선을 이용해 터뜨릴 수 있다.
2. 그렇다면 오른쪽에 어떤 풍선이 존재하던지 그 중 가장 작은 풍선 하나를 남길 수 있게 된다.
3. 남은 두 풍선 중 남기고 싶은 풍선이 더 큰 값이어도 최대 한번 더 작은 풍선을 터뜨릴 수 있기에 해당 풍선을 남길 수 있다.
4. 해당 풍선의 오른쪽에 해당 풍선보다 작은 값이 존재하지 않는 경우 역시 같은 방식으로 남길 수 있다.
 
> 예외
하지만, 해당 풍선의 왼쪽과 오른쪽에 모두 해당 풍선보다 작은 값이 존재한다면 해당 풍선을 남길 수 없게 된다.

 

# 코드



    import java.util.*;

    class Solution {
        public int solution(int[] a) {
        
            int answer = 0;
            int len = a.length;
            
            int[] prevMin = new int[len];
            int[] nextMin = new int[len];
            
            int min = a[0];
            for(int i = 0; i<len; i++){
                if(a[i] < min)
                    min = a[i];
                prevMin[i] = min;
            }
            
            min = a[len-1];
            for(int i = len-1; i>=0; i--){
                if(a[i] < min)
                    min = a[i];
                nextMin[i] = min;
            }
                
            for(int i = 0; i<len; i++){
                if(nextMin[i] == a[i] || prevMin[i] == a[i])
                    answer++;
            }
            
            return answer;
        }
    }
