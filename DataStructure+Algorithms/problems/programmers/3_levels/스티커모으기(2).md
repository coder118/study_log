# 문제 정의

---

### 제약 조건 분석

* 시간 복잡도는 O(N) 선형 시간 내에 해결.
* 스티커에 적힌 숫자는 1 이상 100 이하의 자연수

---

### 패턴 단순화 및 추상화

* 인접한 스티커를 연속해서 선택할 수 없으므로 동적 계획법 기법을 적용.
* 첫 번째 스티커를 뜯는 경우 마지막 스티커를 사용할 수 없음.
* 첫 번째 스티커를 뜯지 않는 경우 마지막 스티커를 선택할 수 있다.
* 원형 제약을 해제하기 위해 첫 번째 스티커 선택 여부에 따라 두 가지 선형 DP 경우로 분리.
* 각 경우에 대해 현재 스티커를 선택하는 경우와 선택하지 않는 경우 중 최댓값을 갱신.

---

### 경계 조건

* N이 1인 경우 해당 스티커의 값을 그대로 반환.
* 첫 번째 스티커를 뜯는 경우 DP 배열은 인덱스 0부터 N-2까지 진행.
* 첫 번째 스티커를 뜯지 않는 경우 DP 배열은 인덱스 1부터 N-1까지 진행.

---

### 최적의 알고리즘

1. 스티커 배열의 길이가 1인 경우 첫 번째 원소를 반환.
2. 첫 번째 스티커를 선택하는 경우를 위한 DP 배열을 생성하고 인덱스 0과 1을 초기화.
3. 첫 번째 스티커를 선택하지 않는 경우를 위한 DP 배열을 생성하고 인덱스 1을 초기화.
4. 첫 번째 경우에 대해 인덱스 2부터 N-2까지 순회하며 최댓값을 갱신.
5. 두 번째 경우에 대해 인덱스 2부터 N-1까지 순회하며 최댓값을 갱신.
6. 두 경우의 최종 최댓값 중 더 큰 값을 반환.

---

# 코드

    class Solution {
        public int solution(int[] sticker) {
            int n = sticker.length;
            
            if (n == 1) {
                return sticker[0];
            }

            int[] dp1 = new int[n];
            dp1[0] = sticker[0];
            dp1[1] = sticker[0];

            for (int i = 2; i < n - 1; i++) {
                dp1[i] = Math.max(dp1[i - 1], dp1[i - 2] + sticker[i]);
            }

            int[] dp2 = new int[n];
            dp2[0] = 0;
            dp2[1] = sticker[1];

            for (int i = 2; i < n; i++) {
                dp2[i] = Math.max(dp2[i - 1], dp2[i - 2] + sticker[i]);
            }

            return Math.max(dp1[n - 2], dp2[n - 1]);
        }
    }
