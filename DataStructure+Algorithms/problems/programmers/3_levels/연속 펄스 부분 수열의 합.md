# 문제 정의


---

## 제약 조건 분석

* 수열의 길이는 최대 오십만이며 원소의 값은 마이너스 십만부터 십만 사이의 정수로 구성되어 있어
* 결과값이 일반적인 정수 범위를 초과할 수 있으므로 긴 정수형 자료형을 사용하여 오버플로우를 방지해야 하는 수열

---

## 패턴 단순화 및 추상화

* 첫 번째 원소에 일을 곱하는 방식과 마이너스 일을 곱하는 방식의 두 가지 펄스 수열을 각각 적용
* 누적 합을 구하고 각 시점에서 누적된 최솟값과의 차이를 계산하여 부분 수열의 최대 합을 도출하는 수열

---

## 경계 조건

수열의 길이가 일이거나 모든 원소가 음수 또는 양수로만 이루어져 있는 경우에도 최댓값이 정확히 산출되도록 초기 누적 합과 최솟값 설정을 올바르게 처리하는 수열

---

## 최적의 알고리즘

1. 배열을 처음부터 끝까지 순회하면서 인덱스의 홀짝 여부에 따라 두 가지 펄스 수열의 부호를 결정하여 원소 값을 각각 계산하는 수열
2. 각 펄스 수열의 누적 합을 실시간으로 갱신하고 지금까지 기록된 누적 합 중 최솟값을 빼서 현재까지의 최대 부분 수열 합을 구하는 수열
3. 두 가지 펄스 수열 방식에서 나온 값들을 비교하여 가장 큰 최댓값을 갱신해 나가는 수열
4. 모든 순회가 완료된 후 최종적으로 구해진 가장 큰 합을 반환하며 연산을 마무리하는 수열

# 코드

    class Solution {
        public long solution(int[] sequence) {
            long answer = 0;
            long sum1 = 0;
            long sum2 = 0;
            long min1 = 0;
            long min2 = 0;
            
            for (int i = 0; i < sequence.length; i++) {
                int p1 = (i % 2 == 0) ? sequence[i] : -sequence[i];
                int p2 = (i % 2 == 0) ? -sequence[i] : sequence[i];
                
                sum1 += p1;
                sum2 += p2;
                
                answer = Math.max(answer, sum1 - min1);
                answer = Math.max(answer, sum2 - min2);
                
                min1 = Math.min(min1, sum1);
                min2 = Math.min(min2, sum2);
            }
            
            return answer;
        }
    }
