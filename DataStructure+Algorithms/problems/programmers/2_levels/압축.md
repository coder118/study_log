# 문제 정의

### 제약 조건 분석
문자열 탐색 및 사전 조회 연산이 다수 발생하나 메시지 길이가 최대 1000으로 매우 짧음.
사전 자료구조로 Map을 활용하면 조회 및 등록 연산을 평균 시간에 처리할 수 있어 전체 시간 복잡도 ON 수준으로 해결 가능함.

### 패턴 단순화 추상화

- 1번부터 26번까지 A부터 Z를 저장한 사전을 구성함.
- 현재 위치에서 시작하는 가장 긴 사전 등록 문자열 w를 탐색함.
- w의 색인 번호를 결과 리스트에 저장함.
- 입력에서 w를 제거하고 다음 글자 c가 존재하면 w+c를 사전에 새로 등록함.
- 문자열 끝에 도달할 때까지 이 과정을 반복함.

### 경계 조건

- 메시지 길이가 1인 경우, 첫 글자의 색인 번호만 출력하고 즉시 종료함.
- 입력의 마지막 글자를 처리할 때는 다음 글자 c가 없으므로 사전에 새로 등록하는 과정을 생략하고 탐색을 종료함.

### 최적의 알고리즘

1. A부터 Z까지의 단어와 색인 번호를 Map 자료구조에 등록하여 초기화함.
2. 현재 위치 인덱스를 관리하며, 사전에 존재하는 가장 긴 단어 w를 탐색함.
3. 찾은 단어 w의 색인 번호를 결과 리스트에 추가함.
4. 다음 글자가 존재할 경우 w+c 단어를 사전에 다음 번호로 등록함.
5. 인덱스를 w의 길이만큼 이동시킨 후 다음 탐색을 진행함.
6. 전체 문자열 처리가 끝나면 리스트를 정수 배열로 변환하여 반환함.

# 코드
    
    import java.util.*;

    class Solution {
        public int[] solution(String msg) {
            Map<String, Integer> dictionary = new HashMap<>();

            for (int i = 0; i < 26; i++) {
                dictionary.put(String.valueOf((char) ('A' + i)), i + 1);
            }

            List<Integer> result = new ArrayList<>();
            int nextIndex = 27;
            int i = 0;

            while (i < msg.length()) {
                String w = "";
                int j = i + 1;

                while (j <= msg.length()) {
                    String sub = msg.substring(i, j);
                    if (!dictionary.containsKey(sub)) {
                        break;
                    }
                    w = sub;
                    j++;
                }

                result.add(dictionary.get(w));

                if (i + w.length() < msg.length()) {
                    String c = String.valueOf(msg.charAt(i + w.length()));
                    dictionary.put(w + c, nextIndex++);
                }

                i += w.length();
            }

            return result.stream().mapToInt(Integer::intValue).toArray();
        }

    }
