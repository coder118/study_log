# 문제 정의

### 제약 조건 분석

틱택토 게임판 크기는 3x3으로 고정

---

### 패턴 단순화 및 추상화

- 선공 O는 후공 X보다 먼저 두므로 O의 개수는 X의 개수와 같거나 1개 많아야 함
- O가 승리하여 게임이 끝난 경우 O의 개수는 X의 개수보다 정확히 1개 많아야 함
- X가 승리하여 게임이 끝난 경우 O의 개수와 X의 개수는 서로 같아야 함
- O와 X가 동시에 승리하는 상황은 나올 수 없다

---

### 경계 조건

- O의 개수에서 X의 개수를 뺀 값이 0 미만이거나 2 이상인 경우 유효하지 않다
- O가 승리했음에도 X의 개수가 O의 개수와 같아질 때까지 게임을 진행한 경우는 유효하지 않다
- X가 승리했음에도 O가 한 번 더 두어 O의 개수가 더 많아진 경우는 유효하지 않다

---

### 최적의 알고리즘

1. 게임판 전체를 순회하며 O의 개수와 X의 개수를 각각 집계
2. 가로 세로 대각선 방향을 검사하여 O의 승리 여부와 X의 승리 여부를 판별
3. 개수 조건인 O의 개수가 X의 개수와 같거나 X의 개수보다 1개 많은지 확인하고 만족하지 않으면 0을 반환
4. 승리 조건인 O가 승리했을 때 O의 개수가 X의 개수보다 1개 많은지 그리고 X가 승리했을 때 O의 개수와 X의 개수가 같은지 확인하여 조건을 모두 만족하면 1을 그렇지 않으면 0을 반환

---

# 코드

class Solution {
    public int solution(String[] board) {
        int oCount = 0;
        int xCount = 0;

        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                char c = board[i].charAt(j);
                if (c == 'O') {
                    oCount++;
                } else if (c == 'X') {
                    xCount++;
                }
            }
        }

        if (oCount < xCount || oCount > xCount + 1) {
            return 0;
        }

        boolean oWin = checkWin(board, 'O');
        boolean xWin = checkWin(board, 'X');

        if (oWin && xWin) {
            return 0;
        }

        if (oWin && oCount != xCount + 1) {
            return 0;
        }

        if (xWin && oCount != xCount) {
            return 0;
        }

        return 1;
    }

    private boolean checkWin(String[] board, char target) {
        for (int i = 0; i < 3; i++) {
            if (board[i].charAt(0) == target && board[i].charAt(1) == target && board[i].charAt(2) == target) {
                return true;
            }
            if (board[0].charAt(i) == target && board[1].charAt(i) == target && board[2].charAt(i) == target) {
                return true;
            }
        }

        if (board[0].charAt(0) == target && board[1].charAt(1) == target && board[2].charAt(2) == target) {
            return true;
        }

        if (board[0].charAt(2) == target && board[1].charAt(1) == target && board[2].charAt(0) == target) {
            return true;
        }

        return false;
    }
}
