# 문제 정의

### 제약 조건 분석


- 최대 격자 크기가 매우 작아 매 요청(최대 100회)마다 BFS/DFS 탐색을 수행해도 시간 초과 없이 충분히 해결할 수 있다.

---

### 패턴 단순화 및 추상화

창고 외부와 연결된 빈 공간을 확장하며 접근 가능한 컨테이너를 제거한다.

- **요청 형태 분기:**
- **크레인(길이 2):** 접근성 상관없이 해당 알파벳 전체 제거.
- **지게차(길이 1):** 외부 공기와 접한 해당 알파벳만 제거.

- **공기 영역 추상화:**
- 격자 외곽을 감싸는 패딩을 두고, 매 지게차 요청마다 (0,0)부터 BFS를 실행해 현재 접근 가능한 외부 공기 영역을 구한다.


---

### 경계 조건

* **외곽 패딩 (Padding):** 창고 테두리 접근성 처리 단순화를 위해 배열 크기를 $(N+2) \times (M+2)$로 확장해 '0'(공기)으로 채운다.
* **공기 연쇄 연결:** 컨테이너 제거로 새로 생긴 빈 공간은 다음 요청 시 내부로 통하는 새로운 탐색 경로가 된다.

---

### 최적의 알고리즘 (BFS 시뮬레이션)

1. **초기화:** $(N+2) \times (M+2)$ 크기 배열을 만들고 중앙에 `storage`를 배치한 뒤 테두리는 '0'으로 채운다.
2. **요청 처리:**
* **크레인:** 배열 전체를 순회해 대상 알파벳을 '0'으로 변경한다.
* **지게차:** (0,0)에서 BFS를 실행해 공기('0')와 접한 대상 알파벳 위치를 찾아 모은 뒤 일괄 '0'으로 변경한다.

3. **반환:** 모든 요청 완료 후 남아있는 알파벳 개수를 센다.

# 코드

    import java.util.*;

    class Solution {
        // 상하좌우 이동을 위한 방향 배열
        private static final int[] dr = {-1, 1, 0, 0};
        private static final int[] dc = {0, 0, -1, 1};

        public int solution(String[] storage, String[] requests) {
            int n = storage.length;
            int m = storage[0].length();

            // 1. 외곽 패딩을 포함한 (n+2) x (m+2) 격자 생성 및 초기화
            char[][] grid = new char[n + 2][m + 2];
            for (int i = 0; i < n + 2; i++) {
                Arrays.fill(grid[i], '0'); // '0'은 외부 공기 또는 빈 공간
            }

            for (int i = 0; i < n; i++) {
                for (int j = 0; j < m; j++) {
                    grid[i + 1][j + 1] = storage[i].charAt(j);
                }
            }

            // 2. 요청 순차 처리
            for (String req : requests) {
                char target = req.charAt(0);

                if (req.length() == 2) {
                    // 크레인 요청: 접근성 상관없이 전체 제거
                    removeWithCrane(grid, target, n, m);
                } else {
                    // 지게차 요청: 외부 공기와 접한 컨테이너만 제거
                    removeWithForklift(grid, target, n, m);
                }
            }

            // 3. 남아있는 컨테이너 개수 세기
            int answer = 0;
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= m; j++) {
                    if (grid[i][j] != '0') {
                        answer++;
                    }
                }
            }

            return answer;
        }

        // 크레인: 대상 알파벳 일괄 제거
        private void removeWithCrane(char[][] grid, char target, int n, int m) {
            for (int i = 1; i <= n; i++) {
                for (int j = 1; j <= m; j++) {
                    if (grid[i][j] == target) {
                        grid[i][j] = '0';
                    }
                }
            }
        }

        // 지게차: (0,0) BFS 탐색으로 공기와 접한 대상만 일괄 제거
        private void removeWithForklift(char[][] grid, char target, int n, int m) {
            boolean[][] visited = new boolean[n + 2][m + 2];
            Queue<int[]> queue = new LinkedList<>();
            List<int[]> toRemove = new ArrayList<>();

            queue.offer(new int[]{0, 0});
            visited[0][0] = true;

            while (!queue.isEmpty()) {
                int[] curr = queue.poll();
                int r = curr[0];
                int c = curr[1];

                for (int d = 0; d < 4; d++) {
                    int nr = r + dr[d];
                    int nc = c + dc[d];

                    if (nr < 0 || nr >= n + 2 || nc < 0 || nc >= m + 2 || visited[nr][nc]) {
                        continue;
                    }

                    if (grid[nr][nc] == '0') {
                        // 빈 공간이면 탐색 계속 진행
                        visited[nr][nc] = true;
                        queue.offer(new int[]{nr, nc});
                    } else if (grid[nr][nc] == target) {
                        // 공기와 맞닿은 대상 알파벳을 발견하면 제거 목록에 추가 
                        visited[nr][nc] = true;
                        toRemove.add(new int[]{nr, nc});
                    }
                }
            }

            // 탐색 완료 후 모아둔 대상만 빈 공간으로 일괄 전환
            for (int[] pos : toRemove) {
                grid[pos[0]][pos[1]] = '0';
            }
        }
    }
