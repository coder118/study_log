# 문제 정의

---

### 제약 조건 분석

* 초항 k는 2 이상 10,000 이하 자연수로 지정
* 구간 목록 ranges의 길이는 1 이상 10,000 이하로 구성
* ranges의 각 원소 [a, b]에서 a는 0 이상 200 이하, b는 -200 초과 0 이하 정수로 정의
* 정적분 계산 결과의 최대값은 충분히 안전한 범위 내 존재

---

### 패턴 단순화 및 추상화

* 초항 k로부터 시작하여 Collatz 추측 알고리즘을 통해 값이 1이 될 때까지 우박수열 생성
* 생성된 각 지점 사이의 구간 면적을 사다리꼴 넓이 공식을 적용하여 계산
* 주어진 시작점과 끝점 범위 [a, n + b]에 대해 구간 내 넓이의 합 산출
* 시작점이 끝점보다 큰 유효하지 않은 구간은 -1 처리

---

### 경계 조건

* 시작 지점이 끝 지점보다 뒤에 위치하는 유효하지 않은 구간 결과는 -1.0 처리
* 시작 지점과 끝 지점이 서로 동일한 구간 결과는 0 처리
* 수열의 전체 길이 n을 정확히 구하여 상대적인 음수 좌표 계산 반영

---

### 최적의 알고리즘

1. 초항 k를 시작으로 값이 1이 될 때까지 우박수열 전체 값 목록 생성
2. 수열의 연속된 두 지점 사이 좌표를 이용해 인접한 1단위 구간들의 사다리꼴 넓이 사전 계산
3. 주어진 구간 [a, b]를 실제 x축 범위 [a, n + b]로 변환
4. 변환된 범위를 검증하여 유효하지 않은 경우 -1.0 반환
5. 유효한 구간에 대해 사전 계산된 사다리꼴 넓이들을 합산하여 결과 배열에 반영

---

# 코드

    import java.util.*;

    class Solution {
        public double[] solution(int k, int[][] ranges) {
            List<Integer> sequence = new ArrayList<>();
            sequence.add(k);

            while (k > 1) {
                if (k % 2 == 0) {
                    k /= 2;
                } else {
                    k = k * 3 + 1;
                }
                sequence.add(k);
            }

            int n = sequence.size() - 1;
            double[] area = new double[n];

            for (int i = 0; i < n; i++) {
                area[i] = (sequence.get(i) + sequence.get(i + 1)) / 2.0;
            }

            double[] answer = new double[ranges.length];

            for (int i = 0; i < ranges.length; i++) {
                int start = ranges[i][0];
                int end = n + ranges[i][1];

                if (start > end) {
                    answer[i] = -1.0;
                } else if (start == end) {
                    answer[i] = 0.0;
                } else {
                    double sum = 0.0;
                    for (int j = start; j < end; j++) {
                        sum += area[j];
                    }
                    answer[i] = sum;
                }
            }

            return answer;
        }
    }
