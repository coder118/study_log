# 문제 정의


### 제약 조건 분석

* 영문 대소문자 구분을 하지 않고 동일하게 처리
* 정렬 기준이 동일한 경우 원래의 순서 보존

---

### 패턴 단순화 및 추상화

* 파일명을 머리, 숫자, 꼬리의 세 부분으로 분리
* 머리 부분은 대소문자 구분 없이 사전 순으로 비교
* 머리 부분이 같으면 숫자 부분을 정수로 변환하여 크기 비교
* 두 기준이 모두 같으면 순서를 변경하지 않고 유지

---

### 경계 조건

* 파일명에 숫자가 두 번 이상 등장할 경우 첫 번째 연속된 숫자 집합만 숫자 부분으로 인식
* 숫자 앞자리에 무의미한 영이 포함된 경우
* 머리 부분에 공백이나 특수문자가 포함될 수 있음

---

### 최적의 알고리즘

1. 입력받은 파일명 목록의 각 요소에 대해 원본 위치 인덱스와 함께 머리, 숫자 부분을 추출
2. 파일명의 첫 번째 숫자 등장 위치를 찾아 머리 부분과 숫자 부분을 정확히 분할
3. 분할된 머리 부분은 모두 소문자 또는 대문자로 변환하여 비교 준비
4. 분할된 숫자 부분은 정수 형태로 변환하여 크기 비교 준비
5. 머리 부분 비교, 숫자 부분 비교, 원본 인덱스 순서 비교를 적용하는 정렬 기준 정의
6. 정의된 정렬 기준에 따라 안정 정렬을 실행한 후 결과 배열 반환

# 코드

    import java.util.*;

    class Solution {
        public String[] solution(String[] files) {
            Arrays.sort(files, new Comparator<String>() {
                @Override
                public int compare(String file1, String file2) {
                    String head1 = getHead(file1);
                    String head2 = getHead(file2);
                    
                    int headCompare = head1.compareToIgnoreCase(head2);
                    if (headCompare != 0) {
                        return headCompare;
                    }
                    
                    int number1 = getNumber(file1);
                    int number2 = getNumber(file2);
                    
                    return Integer.compare(number1, number2);
                }
                
                private String getHead(String file) {
                    int index = 0;
                    while (index < file.length() && !Character.isDigit(file.charAt(index))) {
                        index++;
                    }
                    return file.substring(0, index);
                }
                
                private int getNumber(String file) {
                    int start = 0;
                    while (start < file.length() && !Character.isDigit(file.charAt(start))) {
                        start++;
                    }
                    int end = start;
                    while (end < file.length() && Character.isDigit(file.charAt(end)) && (end - start) < 5) {
                        end++;
                    }
                    return Integer.parseInt(file.substring(start, end));
                }
            });
            
            return files;
        }
    }
