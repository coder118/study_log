# 문제 정의

### 제약 조건 분석

* 주어지는 숫자의 개수는 2개 이상 20개 이하의 자연수
* 각 숫자는 1 이상 50 이하의 자연수
* 목표 숫자는 1 이상 1000 이하의 자연수

---

### 패턴 단순화 및 추상화

* 각 숫자마다 더하는 경우와 빼는 경우 두 가지 선택지가 존재
* 배열의 첫 번째 숫자부터 시작하여 마지막 숫자까지 순차적으로 탐색 진행
* 현재 위치의 숫자를 더하거나 뺀 값을 다음 단계로 전달하는 이진 탐색 구조 형성

---

### 경계 조건

* 배열의 모든 요소를 더해도 목표 숫자에 도달하지 못하는 상황 확인
* 모든 숫자가 동일한 경우의 탐색 결과 확인
* 탐색 깊이가 배열의 전체 길이에 도달했을 때만 정답 여부를 판정하도록 설정

---

### 최적의 알고리즘

1. 현재 탐색 중인 배열의 인덱스와 지금까지의 누적 합계를 매개변수로 갖는 재귀 함수를 정의
2. 인덱스가 배열의 전체 길이와 같아지면 모든 숫자를 탐색한 것이므로 누적 합계가 목표 숫자와 같은지 비교
3. 누적 합계가 목표 숫자와 같으면 1을 반환하고 다르면 0을 반환
4. 인덱스가 배열의 전체 길이보다 작으면 현재 숫자를 더하는 경우와 빼는 경우를 각각 재귀 호출하여 두 결과를 합산
5. 첫 번째 인덱스와 누적 합계 0으로 재귀 탐색을 시작하여 최종 결과값을 반환

# 코드

    class Solution {
        public int solution(int[] numbers, int target) {
            return dfs(numbers, target, 0, 0);
        }

        private int dfs(int[] numbers, int target, int index, int sum) {
            if (index == numbers.length) {
                if (sum == target) {
                    return 1;
                }
                return 0;
            }

            int add = dfs(numbers, target, index + 1, sum + numbers[index]);
            int subtract = dfs(numbers, target, index + 1, sum - numbers[index]);

            return add + subtract;
        }
    }
