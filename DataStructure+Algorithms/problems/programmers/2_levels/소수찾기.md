# 문제 정의

---

### 제약 조건 분석

* 문자열 길이 1 이상 7 이하 구성
* 숫자 범위 0부터 9까지 종이 조각 존재
* 최대 7자리 숫자 완전탐색 시간 복잡도 충분히 통과 가능

---

### 패턴 단순화 및 추상화

* 종이 조각으로 만들 수 있는 모든 숫자 조합 순열 탐색
* 중복 숫자에 대한 중복 계산 방지 위해 집합 구조 활용
* 생성된 각 숫자에 대해 소수 여부 판별 진행
* 소수 조건 만족 시 최종 결과 값 증가

---

### 경계 조건

* 0 또는 1은 소수 대상에서 제외 처리
* 접두사 0으로 시작하는 숫자는 동일 숫자로 통합 관리
* 중복된 수 조합은 단 1회만 소수 판별 진행

---

### 최적의 알고리즘

1. 숫자를 저장할 중복 제거 집합 생성
2. 재귀 함수 이용해 모든 길이의 숫자 순열 생성 진행
3. 생성된 숫자를 정수 형태로 변환 후 집합 추가
4. 집합 내부의 모든 숫자에 대해 소수 판별 실행
5. 제곱근 범위까지 나누어 떨어지는지 검증
6. 최종 판별된 소수의 총개수 반환

---

# 코드

    import java.util.*;

    class Solution {
        public int solution(String numbers) {
            Set<Integer> numberSet = new HashSet<>();
            boolean[] visited = new boolean[numbers.length()];

            generate("", numbers, visited, numberSet);

            int count = 0;
            for (int num : numberSet) {
                if (isPrime(num)) {
                    count++;
                }
            }

            return count;
        }

        private void generate(String current, String numbers, boolean[] visited, Set<Integer> numberSet) {
            if (!current.isEmpty()) {
                numberSet.add(Integer.parseInt(current));
            }

            for (int i = 0; i < numbers.length(); i++) {
                if (!visited[i]) {
                    visited[i] = true;
                    generate(current + numbers.charAt(i), numbers, visited, numberSet);
                    visited[i] = false;
                }
            }
        }

        private boolean isPrime(int num) {
            if (num < 2) {
                return false;
            }

            for (int i = 2; i <= Math.sqrt(num); i++) {
                if (num % i == 0) {
                    return false;
                }
            }

            return true;
        }
    }
