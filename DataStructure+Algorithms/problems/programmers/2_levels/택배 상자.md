# 문제 정의

### 제약 조건 분석

order의 길이가 최대 1,000,000이므로 시간 복잡도 O(N) 선에서 해결해야 함

---

### 패턴 단순화 및 추상화

* 메인 벨트 동작: 1번 상자부터 N번 상자까지 순서대로 지나가는 큐 형태로 동작
* 보조 벨트 동작: 맨 위의 상자만 꺼낼 수 있는 스택 형태로 동작
* 실을 상자 탐색: 현재 실어야 하는 상자가 올 때까지 메인 벨트의 상자를 보조 벨트로 이동

---

### 경계 조건

* 보조 벨트에 마지막으로 넣은 상자와 현재 순서가 일치하면 즉시 꺼내서 트럭에 적재
* 메인 벨트의 상자가 order의 길이인 N을 초과하고 보조 벨트의 맨 위 상자도 일치하지 않는 경우 작업 종료
* 보조 벨트에 모든 상자를 넣었다가 역순으로 모두 꺼내는 경우 처리

---

### 최적의 알고리즘

1. 메인 벨트에서 보낼 상자 번호를 나타낼 변수 box를 1로 초기화하고 보조 벨트 역할을 할 스택을 생성한다
2. order 배열을 순회하며 각 상자를 적재한다
3. box가 현재 실어야 할 상자 번호 이하인 동안 box를 스택에 넣고 1씩 증가시킨다
4. 스택의 맨 위 상자가 현재 실어야 할 상자 번호와 같으면 스택에서 꺼내고 적재 개수를 증가시킨다
5. 스택의 맨 위 상자가 현재 실어야 할 상자 번호와 다르면 더 이상 실을 수 없으므로 반복을 종료하고 적재한 상자 수를 반환한다



# 코드 

    import java.util.Stack;

    class Solution {
        public int solution(int[] order) {
            int answer = 0;
            Stack<Integer> belt = new Stack<>();
            int currentBox = 1;

            for (int target : order) {
                while (currentBox <= target) {
                    belt.push(currentBox);
                    currentBox++;
                }

                if (!belt.isEmpty() && belt.peek() == target) {
                    belt.pop();
                    answer++;
                } else {
                    break;
                }
            }

            return answer;
        }
    }
