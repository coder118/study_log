# 문제 정의

완전 탐색으로 풀어야겠다는 생각
dfs 방식으로 접근했다가 실패했다.

눈 여겨볼 곳은 0번째 행이 아닌 1번째 행이다. 1번째 행의 각 land[1][0], land[1][1], land[1][2], land[1][3]에 값을 갱신해줄 것이다.
1. 먼저, land[1][0]은 0번째 열을 선택했다고 생각해보자. 1번째 행의 윗 행이 0번째 행에서
2. 0번째 열을 제외한 land[0][1], land[0][2], land[0][3] 중에 값을 고를 수 있고, 최대값은 5가된다.
3. 기존 land[1][0] 값인 5에 5를 더한 10으로 land[1][0]의 값을 갱신시켜준다.
4. 다음과 같이 파란글씨(기존값)에서 최대값을 더한 굵은 글씨로 갱신된다.
5. 이 방식으로 n-1행까지 값을 갱신해주면
6. 마지막행에 갱신된 값 중 최대값을 뽑으면 정답이 된다.

# 코드

    class Solution {
        int solution(int[][] land) {
            int answer = 0;
            for(int i = 1 ; i< land.length; i++){
                land[i][0] += Math.max(land[i-1][1],Math.max(land[i-1][2],land[i-1][3]));
                land[i][1] += Math.max(land[i-1][0],Math.max(land[i-1][2],land[i-1][3]));
                land[i][2] += Math.max(land[i-1][0],Math.max(land[i-1][1],land[i-1][3]));
                land[i][3] += Math.max(land[i-1][0],Math.max(land[i-1][1],land[i-1][2]));
            }
            for(int i = 0; i < 4; i++){
                answer = Math.max(answer,land[land.length-1][i]);
            }
            return answer;
        }
    }
