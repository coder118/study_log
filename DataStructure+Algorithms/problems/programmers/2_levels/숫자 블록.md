# 문제 정의 및 제약 조건 분석

* 전체 구간을 직접 순회하는 방식의 제한 사항 분석
* 개별 숫자에 대한 효율적인 약수 탐색 필요성 확인

# 패턴 단순화 및 추상화

* 특정 위치의 가장 큰 약수 선택 규칙 적용
* 일천만 이하의 조건을 만족하는 약수 탐색
* 소수일 때 일 번 블록 배치 규칙 설정

# 경계 조건

* 일 번 도로의 0 반환 처리
* 일천만 이하의 가장 큰 약수 제한 조건 확인
* 약수가 없는 소수 구간에 대한 예외 처리

# 알고리즘 설계

1. 구간 내 모든 정수에 대한 반복문 순회 구성
2. 제곱근 범위 내에서의 약수 탐색 및 조건 검사
3. 조건을 만족하는 최대 약수 계산 및 결과 저장

# 코드

class Solution {
    public int[] solution(long begin, long end) {
        int length = (int)(end - begin + 1);
        int[] answer = new int[length];
        
        for (int i = 0; i < length; i++) {
            long target = begin + i;
            answer[i] = getMaxDivisor(target);
        }
        
        return answer;
    }
    
    private int getMaxDivisor(long n) {
        if (n == 1) {
            return 0;
        }
        
        int maxDivisor = 1;
        for (long i = 2; i * i <= n; i++) {
            if (n % i == 0) {
                if (n / i <= 10000000) {
                    return (int)(n / i);
                }
                if (i <= 10000000) {
                    maxDivisor = (int)i;
                }
            }
        }
        
        return maxDivisor;
    }
}
