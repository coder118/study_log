# 문제 정의

### 제약 조건 분석

* 컬럼의 개수는 최대 8개로 제한.
* 튜플의 개수는 최대 20개로 제한.
* 컬럼 조합의 전체 경우의 수는 2의 8제곱 마이너스 1인 255가지. 완전 탐색 가능.

---

### 패턴 단순화 및 추상화

* 전체 조합 탐색: 컬럼 들로 만들 수 있는 모든 부분집합 조합 생성.
* 유일성 검증: 선택한 컬럼 조합으로 모든 튜플을 중복 없이 식별 가능한지 확인.
* 최소성 검증: 유일성을 만족하는 조합 중 이미 선택된 후보키의 부분집합을 포함하는지 확인.

---

### 경계 조건

* 최소성 우선: 유일성을 만족하더라도 이미 후보키로 선정된 컬럼 조합을 포함하면 exclusion 처리.
* 튜플 식별: 튜플 구성 값이 동일한 경우가 없어야 유일성 성립.
* 컬럼 조합 크기 순 탐색: 크기가 작은 컬럼 조합부터 탐색하여 최소성 검증 단순화.

---

### 최적의 알고리즘

1. 컬럼 index의 모든 부분집합 조합을 크기 순으로 생성.
2. 현재 컬럼 조합이 유일성을 만족하는지 튜플 집합 변환으로 확인.
3. 이미 등록된 후보키 집합이 현재 조합에 포함되는지 최소성 확인.
4. 두 조건을 모두 만족하면 후보키 목록에 추가하고 탐색 완료 후 최종 후보키 개수 반환.


# 코드

    import java.util.*;

    class Solution {
        private int colLen;
        private int rowLen;
        private List<List<Integer>> candidateKeys = new ArrayList<>();

        public int solution(String[][] relation) {
            rowLen = relation.length;
            colLen = relation[0].length;

            for (int size = 1; size <= colLen; size++) {
                makeCombination(0, size, new ArrayList<>(), relation);
            }

            return candidateKeys.size();
        }

        // 1. 모든 컬럼 조합을 백트래킹으로 생성
        private void makeCombination(int start, int targetSize, List<Integer> current, String[][] relation) {
            if (current.size() == targetSize) {
                // 최소성 검증
                if (!isMinimal(current)) {
                    return;
                }
                // 유일성 검증
                if (isUnique(current, relation)) {
                    candidateKeys.add(new ArrayList<>(current));
                }
                return;
            }

            for (int i = start; i < colLen; i++) {
                current.add(i);
                makeCombination(i + 1, targetSize, current, relation);
                current.remove(current.size() - 1);
            }
        }

        // 2. 최소성 검증: 이미 등록된 후보키의 모든 요소가 현재 조합에 포함되는지 확인
        private boolean isMinimal(List<Integer> current) {
            for (List<Integer> key : candidateKeys) {
                if (current.containsAll(key)) {
                    return false;
                }
            }
            return true;
        }

        // 3. 유일성 검증: 선택된 컬럼들의 값으로 튜플 식별 가능 여부 확인
        private boolean isUnique(List<Integer> current, String[][] relation) {
            Set<String> set = new HashSet<>();

            for (int r = 0; r < rowLen; r++) {
                StringBuilder sb = new StringBuilder();
                for (int colIndex : current) {
                    sb.append(relation[r][colIndex]).append("/");
                }
                set.add(sb.toString());
            }

            return set.size() == rowLen;
        }
    }
