# 문제 정의

### 제약 조건 분석

* targets의 길이가 최대 500,000 => 단순 전체 비교 시 시간 초과가 발생할 수 있음
* 요격 미사일의 개수를 최소화하려면 x 좌표 기준 정렬 후 그리디 알고리즘을 적용하는 접근 필요

---

### 패턴 단순화 및 추상화

* 폭격 미사일의 끝 지점을 기준으로 오름차순 정렬
* 정렬된 미사일을 순회하며 현재 지정된 요격 위치보다 시작 지점이 뒤에 있는 경우 새로운 요격 미사일 필요
* 새로운 요격 미사일은 해당 폭격 미사일의 끝 지점 직전에 발사되는 것으로 간주하여 위치 업데이트

---

### 경계 조건

* 항상 끝 좌표가 시작 좌표보다 큼
* 요격 위치 초기값은 미사일 좌표 범위에 포함되지 않는 음수 또는 0으로 설정
* 시작 지점이 이전 요격 위치와 같거나 큰 경우 요격할 수 없으므로 새로운 요격 미사일 발사 필요

---

### 최적의 알고리즘

1. 폭격 미사일 목록을 끝 지점 기준으로 오름차순 정렬함
2. 요격 위치 변수를 0으로, 정답 개수 변수를 0으로 초기화함
3. 정렬된 각 폭격 미사일에 대해 다음 과정을 수행함
    * 폭격 미사일의 시작 지점이 현재 요격 위치보다 크거나 같으면 새로운 요격 미사일 발사
    * 정답 개수를 1 증가시킴
    * 요격 위치를 현재 폭격 미사일의 끝 지점으로 업데이트함

4. 모든 폭격 미사일을 순회한 후 최종 정답 개수를 반환함

# 코드

    import java.util.Arrays;

    class Solution {
        public int solution(int[][] targets) {
            int answer = 0;
            
            Arrays.sort(targets, (o1, o2) -> Integer.compare(o1[1], o2[1]));
            
            int lastInterceptPos = 0;
            
            //  미사일 순회하며 그리디
            for (int[] target : targets) {
                int start = target[0];
                int end = target[1];
                
                // 현재 미사일의 시작 지점이 마지막 요격 위치보다 크거나 같으면 기존 요격 미사일로 처리 불가능
                if (start >= lastInterceptPos) {
                    answer++;
                    lastInterceptPos = end; // 끝 지점에서 요격한 것으로 갱신
                }
            }
            
            return answer;
        }
    }
