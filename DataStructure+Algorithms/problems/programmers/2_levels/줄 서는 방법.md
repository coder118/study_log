# 문제 정의

### 제약 조건 분석

N = 20일 때 전체 순열의 개수인 N!은 너무 커서 시간 초과가 발생.
O(N) 또는 O(N^2) 내에 K번째 순열을 직접 계산해내는 접근이 필요

### 패턴 단순화, 추상화

- K를 (N-1)!로 나누면, 전체 탐색 없이 첫 번째 자리에 들어갈 숫자의 위치(인덱스)를 바로 결정 가능
- 이 과정을 남은 숫자에 대해 자릿수별로 반복 수행하는 자릿수 단위 결정 문제로 추상화된다.


### 경계 조건
1. 사용된 숫자 관리 및 갱신 : 숫자를 하나 선택하면 해당 숫자는 다음 자릿수 선택 후보에서 제거

2. 팩토리얼 계산 overflow : N! 값은 N=20까지 가므로 long 타입 사용


### 최적의 알고리즘

K의 몫을 통해 어떤 숫자가 와야 하는지 탐색 없이 즉시 확정 할 수 있다



# 코드


    import java.util.ArrayList;

    class Solution {
        public int[] solution(int n, long k) {
            int[] answer = new int[n];
            ArrayList<Integer> numbers = new ArrayList<>();
            
            long fact = 1;
            for (int i = 1; i <= n; i++) {
                numbers.add(i);
                fact *= i;
            }
            
            // 0-based 인덱스로 변환
            k--;
            
            for (int i = 0; i < n; i++) {
                fact /= (n - i); // (n - 1 - i)! 계산
                int index = (int) (k / fact);
                
                answer[i] = numbers.get(index);
                numbers.remove(index);
                
                k %= fact;
            }
            
            return answer;
        }
    }
