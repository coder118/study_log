# 문제 정의

### 제약 조건 분석

시간 복잡도 O(log N) 탐색 적용. 

---

### 패턴 단순화 및 추상화

* 전체 대각선 동작: 전체 직사각형을 가로와 세로의 최대공약수 개수만큼 반복되는 작은 직사각형 구조로 분할.
* 단위 블록 동작: 최대공약수로 나누어진 최소 단위 직사각형 내부에서 대각선이 지나는 격자칸 개수 측정.
* 사용 불가 상자 탐색: 가로 W_sub와 세로 H_sub 크기의 최소 단위에서 대각선이 지나는 격자칸 개수를 W_sub 더하기 H_sub 빼기 1 공식을 적용해 계산.

---

### 경계 조건

* 가로와 세로 길이가 동일한 경우: 최소 단위가 1 대 1 정사각형으로 변환. 대각선이 지나는 격자칸 개수는 변의 길이와 동일하게 처리.
* 가로와 세로 중 한쪽이 다른 쪽의 배수 관계인 경우: 최대공약수가 작은 쪽의 길이로 설정됨을 반영.
* 정수 오버플로우 경계: 가로와 세로의 곱인 전체 격자 수 계산 시 32비트 정수 범위를 초과하므로 64비트 정수 타입 변환 후 계산 진행.

---

### 최적의 알고리즘

1. 가로 W와 세로 H의 최대공약수를 구하는 유클리드 호제법 함수 정의.
2. 전체 정사각형 개수인 W 곱하기 H를 64비트 정수형으로 계산.
3. 대각선이 지나가며 사용할 수 없게 되는 정사각형 총 개수인 W 더하기 H 빼기 최대공약수 연산 수행.
4. 전체 정사각형 개수에서 사용할 수 없는 정사각형 개수를 차감한 최종 결과 반환.


# 코드


    class Solution {
        public long solution(int w, int h) {
            long longW = (long) w;
            long longH = (long) h;
            
            long totalSquares = longW * longH;
            long gcdValue = gcd(longW, longH);
            long disabledSquares = longW + longH - gcdValue;
            
            return totalSquares - disabledSquares;
        }
        
        private long gcd(long a, long b) {
            while (b != 0) {
                long temp = a % b;
                a = b;
                b = temp;
            }
            return a;
        }
    }
