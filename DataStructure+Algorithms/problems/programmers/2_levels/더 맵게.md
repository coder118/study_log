# 문제 정의

1. 먼저, 결과를 담을 answer와 우선순위 큐 queue를 선언한다. 우선순위 큐에는 오름차순으로 정렬되어 저장될 것이다.
2. for 문을 통해 scoville 배열에 담긴 모든 스코빌 지수를 queue에 추가한다.
3. while 문을 통해 현재 큐에 담긴 가장 낮은 스코빌 지수가 K보다 클 때까지 반복하여 음식을 섞는다.
4. 만약, queue의 사이즈가 1인 경우 K를 넘길 방법이 없으므로 -1을 리턴한다.
그렇지 않으면, 스코빌 지수가 가장 낮은 두 음식을 꺼내 섞은 다음 다시 큐에 추가한다.

가장 낮은 스코빌 지수 + (두 번째로 낮은 스코빌 지수 * 2)

5. 음식을 섞은 후 answer를 증가시킨다.


# 코드

    import java.util.PriorityQueue;

    class Solution {
        public int solution(int[] scoville, int K) {
            // 결과를 담을 answer
            int answer = 0;
            // 우선순위 큐 선언
            PriorityQueue<Integer> queue = new PriorityQueue<>();
            
            // scoville 배열 queue에 담기
            for (int i = 0; i < scoville.length; i++) {
                queue.add(scoville[i]);
            }
            
            // 가장 먼저 나올 스코빌 지수가 K 보다 작으면 반복
            while (queue.peek() < K) {
                // queue의 사이즈가 1이면 K를 넘을 방법이 없음
                if (queue.size() == 1) return -1;
                
                // 음식 섞기
                queue.add(queue.poll() + (queue.poll() * 2));
                answer++;
            }
            
            return answer;
        }
    }
