# 문제 정의


### 제약 조건 분석
모든 원소의 약수를 개별 비교하는 O(N^2) 탐색은 시간 초과 발생.
배열 전체의 최대공약수(GCD)를 구하고 상대 배열을 검증하는 O(N log M) 접근법 필요.

### 패턴 단순화, 추상화
배열 A의 모든 원소를 나눌 수 있는 수는 배열 A 전체의 최대공약수 gcdA의 약수뿐임.

조건 1(철수 카드는 모두 나누고 영희 카드는 하나도 못 나눔)을 만족하는 가장 큰 수는 gcdA가 배열 B의 어떤 원소도 나누지 못할 때의 gcdA값으로 단축됨.
이를 두 배열에 대해 각각 독립적으로 수행한 뒤 최댓값을 선택하는 문제로 추상화.

### 경계 조건

최대공약수가 1인 경우: 1은 모든 수를 나눌 수 있으므로 상대 배열의 원소를 나눌 수 없는 조건(양의 정수 a > 1)을 만족하지 못해 자동 제외 대상.

조건 미충족 시 처리: 두 최대공약수 모두 상대 배열의 원소를 나누어 떨어뜨린다면 만족하는 a가 없으므로 0 반환.

### 최적의 알고리즘 
유클리드 호제법 함수 구현두 수 a, b의 최대공약수를 빠르게 구하는 유클리드 호제법 알고리즘 작성.


# 코드

    import java.util.Arrays;

    class Solution {
    public int solution(int[] arrayA, int[] arrayB) {
            int answer = 0;
            int n = arrayA.length;
            int m = arrayB.length;

            Arrays.sort(arrayA);
            Arrays.sort(arrayB);

            // 각 배열의 최대공약수 구하기
            int x = arrayA[0];
        
            for (int i = 1; i < n; i++) {
                x = gcd(arrayA[i], x);
            }

            int y = arrayB[0];
        
            for (int i = 1; i < m; i++) {
                y = gcd(arrayB[i], y);
            }
        
            // 다른 배열의 원소 중 하나라도 나눌 수 없는지 확인
            if (!divided(arrayB, x)) {
                answer = Math.max(answer, x);
            }

            if (!divided(arrayA, y)) {
                answer = Math.max(answer, y);
            }

            return answer;
        }

        // 유클리드 호제법(단, x > y)
        public int gcd(int x, int y) {	
            if (y == 0) {
                return x;
            } else {
                return gcd(y, x % y);
            }
        }


        public boolean divided(int[] arr, int a) {
            boolean divided = false;
            
            if (a <= 1) {
                return true;
            }
            
            int n = arr.length;
            
            for (int i = 0; i < n; i++) {
                if (arr[i] % a == 0) {
                    divided = true;
                }
            }
            
            return divided;
        }
    }
