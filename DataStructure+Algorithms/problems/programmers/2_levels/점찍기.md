# 문제 정의

### 제약 조건 분석

* k와 d가 최대 1,000,000이므로 이중 반복문 사용 시 시간 초과 발생
* x 좌표를 k씩 늘려가며 각 x 위치에서 가능한 y의 최대 개수를 구하는 접근 필요

---

### 패턴 단순화 및 추상화

* 피타고라스 정리를 이용해 x 위치에 따른 y의 최댓값 계산
* y의 최댓값은 루트 d의 제곱 마이너스 x의 제곱 이하의 정수
* 해당 x 위치에서 찍을 수 있는 y 좌표의 개수는 y의 최댓값을 k로 나눈 몫에 1을 더한 값
* 제곱 연산 시 정수 범위 초과 위험이 있으므로 롱 타입 변환 필수

---

### 경계 조건

* x가 0일 때 y축 위에 찍히는 점의 개수를 올바르게 합산
* d의 제곱 마이너스 x의 제곱 연산 결과가 항상 0 이상이므로 음수 제곱근 계산 발생 안 함
* 모든 점의 총합이 정수 범위를 넘을 수 있으므로 결과 변수를 롱 타입으로 선언

---

### 최적의 알고리즘

* x를 0부터 d까지 k씩 증가시키면서 반복문 실행
* 제곱근 함수로 y의 최댓값을 구한 뒤 k로 나눈 몫에 1을 더해 정답에 누적

# 코드

    class Solution {
        public long solution(int k, int d) {
            long answer = 0;
            long maxDistance = (long) d * d;

            for (long x = 0; x <= d; x += k) {
                long maxY = (long) Math.sqrt(maxDistance - (x * x));
                answer += (maxY / k) + 1;
            }

            return answer;
        }
    }
