# 문제 정의 및 제약 조건 분석

* 표의 행을 이동하고 삭제 및 복구하는 프로그램을 작성
* 행의 최대 개수가 백만이며 명령어 개수가 이십만 개이므로 효율적인 자료구조 선택 필수
* 제한 시간 내에 수행하기 위해 시간 복잡도 최적화 수행

# 패턴 단순화 및 추상화

* 양방향 연결 리스트 구조를 배열로 구현하여 각 행의 이전과 다음 위치 관리
* 삭제된 행의 정보를 스택에 저장하여 최근 삭제 항목 추적
* 현재 선택된 행의 위치를 변수로 갱신하며 연산 수행

# 경계 조건 

* 맨 첫 행과 맨 마지막 행에서의 이동 제약 사항 처리
* 마지막 행 삭제 시 바로 윗 행을 선택하도록 분기 처리
* 복구할 행이 없는 상태에서의 명령 입력 예외 상황 방지

# 알고리즘 설계

1. 크기가 백만인 이전 행과 다음 행 배열을 생성하여 초기 연결 설정
2. 위아래 이동 명령어에 따라 현재 행 포인터 변경
3. 삭제 명령어 수행 시 현재 행을 스택에 보관하고 연결 관계 재조정
4. 복구 명령어 수행 시 스택에서 항목을 꺼내어 끊어진 연결 복원
5. 최종 삭제 여부를 확인하여 결과 문자열 구성

# 코드 

    import java.util.Stack;

    class Solution {
        public String solution(int n, int k, String[] cmd) {
            int[] prev = new int[n];
            int[] next = new int[n];
            
            for (int i = 0; i < n; i++) {
                prev[i] = i - 1;
                next[i] = i + 1;
            }
            next[n - 1] = -1;
            
            Stack<Node> deleted = new Stack<>();
            
            for (String c : cmd) {
                char command = c.charAt(0);
                if (command == 'U') {
                    int x = Integer.parseInt(c.substring(2));
                    while (x-- > 0) {
                        k = prev[k];
                    }
                } else if (command == 'D') {
                    int x = Integer.parseInt(c.substring(2));
                    while (x-- > 0) {
                        k = next[k];
                    }
                } else if (command == 'C') {
                    deleted.push(new Node(k, prev[k], next[k]));
                    if (prev[k] != -1) {
                        next[prev[k]] = next[k];
                    }
                    if (next[k] != -1) {
                        prev[next[k]] = prev[k];
                    }
                    
                    if (next[k] != -1) {
                        k = next[k];
                    } else {
                        k = prev[k];
                    }
                } else if (command == 'Z') {
                    Node node = deleted.pop();
                    if (node.prev != -1) {
                        next[node.prev] = node.idx;
                    }
                    if (node.next != -1) {
                        prev[node.next] = node.idx;
                    }
                }
            }
            
            boolean[] isDeleted = new boolean[n];
            while (!deleted.isEmpty()) {
                isDeleted[deleted.pop().idx] = true;
            }
            
            StringBuilder sb = new StringBuilder();
            for (int i = 0; i < n; i++) {
                if (isDeleted[i]) {
                    sb.append('X');
                } else {
                    sb.append('O');
                }
            }
            
            return sb.toString();
        }
        
        static class Node {
            int idx, prev, next;
            public Node(int idx, int prev, int next) {
                this.idx = idx;
                this.prev = prev;
                this.next = next;
            }
        }
    }
