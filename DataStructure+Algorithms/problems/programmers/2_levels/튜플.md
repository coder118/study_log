# 문제 정의

### 제약 조건 분석

* 원소의 개수가 유한하며 중복된 원소가 없는 튜플이 대상

---

### 패턴 단순화 및 추상화

* 집합의 크기는 원소 개수에 따라 1개부터 순차적으로 증가
* 원소 개수가 작은 집합부터 차례대로 확인하면 새로 추가된 원소가 바로 해당 순서의 튜플 원소로 결정
* 문자열을 각 집합 단위로 분리한 뒤 포함된 원소의 개수를 기준하여 오름차순 정렬
* 앞선 집합에 등장하지 않은 새로운 원소를 순서대로 배열에 추가하여 최종 튜플 완성

---

### 경계 조건

* 원소가 1개만 존재하는 최단 길이 문자열 입력 상황 확인
* 숫자 원소가 여러 자릿수로 구성되어 문자열 파싱 시 정확한 분리가 필요한 상황 확인
* 집합의 순서가 크기순으로 정렬되어 있지 않고 무작위로 섞여서 주어지는 상황 확인

---

### 최적의 알고리즘

1. 입력 문자열의 양 끝 중괄호를 제거하고 각 집합 단위로 문자열을 분리
2. 분리된 집합들을 포함된 원소의 개수를 기준하여 오름차순으로 정렬
3. 각 집합을 순회하며 내부에 포함된 숫자들을 순차적으로 확인
4. 이미 결과에 포함된 숫자가 아니라면 해당 숫자를 결과 배열에 추가 및 기록
5. 모든 집합의 확인이 완료되면 완성된 튜플 배열을 반환

# 코드

    import java.util.*;

    class Solution {
        public int[] solution(String s) {
            String trimmed = s.substring(2, s.length() - 2);
            String[] sets = trimmed.split("\\}\\,\\{");
            
            Arrays.sort(sets, (a, b) -> Integer.compare(a.length(), b.length()));
            
            ArrayList<Integer> result = new ArrayList<>();
            Set<Integer> visited = new HashSet<>();
            
            for (String setStr : sets) {
                String[] numbers = setStr.split(",");
                for (String numStr : numbers) {
                    int num = Integer.parseInt(numStr);
                    if (!visited.contains(num)) {
                        visited.add(num);
                        result.add(num);
                    }
                }
            }
            
            int[] answer = new int[result.size()];
            for (int i = 0; i < result.size(); i++) {
                answer[i] = result.get(i);
            }
            
            return answer;
        }
    }
