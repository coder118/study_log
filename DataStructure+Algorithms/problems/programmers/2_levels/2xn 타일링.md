# 문제 정의

---

### 제약 조건 분석

* 가로 길이 n은 60,000 이하의 자연수.
* 시간 복잡도는 선형 시간 내에 해결해야 함.
* 결과값은 1,000,000,007로 나눈 나머지를 출력.

---

### 패턴 단순화 및 추상화

* 가로 길이가 1일 때 타일을 놓는 방법은 세로 타일 1개 배치 1가지.
* 가로 길이가 2일 때 타일을 놓는 방법은 세로 타일 2개 배치, 가로 타일 2개 배치 2가지.
* 가로 길이가 n일 때 가장 오른쪽 끝을 채우는 방식은 세로 타일 1개를 붙이거나 가로 타일 2개를 붙이는 2가지 경우로 분리.
* 따라서 n을 채우는 방법의 수는 n -1을 채우는 방법의 수와 n - 2를 채우는 방법의 수의 합과 동일.
* 피보나치 수열과 동일한 점화식 구조를 형성.

---

### 경계 조건

* n이 1일 때 결과값은 1.
* n이 2일 때 결과값은 2.
* 반복문 수행 시 매 연산마다 1,000,000,007로 나눈 나머지를 저장하여 정수 오버플로우 방지.

---

### 최적의 알고리즘

1. n이 1인 경우 1을 반환.
2. n이 2인 경우 2를 반환.
3. n 크기 플러스 1의 배열을 생성하거나 변수 두 개를 활용해 이전 값들을 관리.
4. 3부터 n까지 순회하며 이전 두 값의 합을 1,000,000,007로 나눈 나머지를 계산하여 갱신.
5. 최종적으로 n번째 위치의 값을 반환.

---

# 코드

    class Solution {
        public int solution(int n) {
            if (n == 1) {
                return 1;
            }
            if (n == 2) {
                return 2;
            }

            int prev2 = 1;
            int prev1 = 2;
            int current = 0;

            for (int i = 3; i <= n; i++) {
                current = (prev1 + prev2) % 1000000007;
                prev2 = prev1;
                prev1 = current;
            }

            return current;
        }
    }
