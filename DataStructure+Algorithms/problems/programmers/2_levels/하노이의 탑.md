# 문제 정의


### 제약 조건 분석
n은 15 이하의 자연수다. 단순 재귀를 이용한 하노이의 탑 이동 횟수는 2n−1번이다. 
n=15일 때 이동 횟수는 32,767번으로 매우 적으므로 O(2N) 시간 복잡도를 가지는 재귀(DFS) 알고리즘으로 충분히 해결 가능

### 패턴 단순화, 추상화
n개의 원판을 1번 기둥에서 3번 기둥으로 옮기는 최적의 과정을 세 가지 단계의 재귀 구조로 추상화한다.

맨 아래의 n번 원판을 제외한 위쪽 n−1개 원판을 출발지에서 경유지로 이동시킨다.

맨 아래의 n번 원판을 출발지에서 목적지로 이동시킨다.

경유지에 옮겨두었던 n−1개 원판을 목적지로 이동시킨다.

이동 경로를 [출발 기둥, 도착 기둥] 형태의 배열로 만들어 결과 리스트에 순서대로 기록한다.

### 경계 조건

재귀 탈출 조건 : 옮겨야 하는 원판의 개수 n이 1인 경우, 더 이상 분할하지 않고 원판을 바로 목적지로 이동([start, to]) 후 재귀 호출을 종료한다.


### 최적의 알고리즘
재귀 / 분할 정복

1. n개의 원판을 옮기기 위해 n−1개 원판을 경유지로 옮기는 재귀 함수 호출을 수행한다.
2. 가장 큰 원판을 목적지로 옮긴 이동 기록을 저장한다.
3. 경유지에 있던 n−1개 원판을 다시 목적지로 옮기는 재귀 함수 호출을 수행한다.
4. 모든 호출이 완료되면 저장된 이동 경로들을 2차원 배열 형태로 반환한다.


# 코드

    import java.util.ArrayList;
    import java.util.List;

    class Solution {
        
        private List<int[]> moves = new ArrayList<>();

        public int[][] solution(int n) {
            // 1번 기둥에서 3번 기둥으로 n개의 원판을 이동 (경유지는 2번 기둥)
            hanoi(n, 1, 3, 2);
            
            // 이동 경로 결과를 2차원 배열로 변환하여 반환
            return moves.toArray(new int[moves.size()][]);
        }

        private void hanoi(int n, int start, int to, int via) {
            // 경계 조건 : 원판이 1개일 경우 목적지로 바로 이동 후 종료
            if (n == 1) {
                moves.add(new int[]{start, to});
                return;
            }

            //  n-1개 원판을 출발지에서 경유지로 이동
            hanoi(n - 1, start, via, to);

            // 가장 큰 n번 원판을 출발지에서 목적지로 이동
            moves.add(new int[]{start, to});

            //  경유지에 놓인 n-1개 원판을 목적지로 이동
            hanoi(n - 1, via, to, start);
        }
    }
