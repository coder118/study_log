# 문제 정의

1. 배열 A와 B를 Arrays.sort() 메서드를 통해 오름차순 정렬한다.
2. 배열의 길이만큼 순회하여 A는 순서대로, B는 역순으로 접근하여 둘을 곱한 뒤 answer에 더한다.
3. A의 가장 작은 수부터, B의 큰 수부터 접근하여 곱한 값들을 더하면 최솟값을 구할 수 있다.
4. 만약, 최댓값을 구하려면 큰 값은 큰 값끼리 곱해야 유리하므로 내림차순으로 정렬 후 배열 A와 B를 순차적으로 접근하여 곱한 값들을 더하여 구할 수 있다.

# 코드

    import java.util.Arrays;

    class Solution {
        public int solution(int []A, int []B) {
            int answer = 0;
            
            // 배열 A와 B를 오름차순으로 정렬
            Arrays.sort(A);
            Arrays.sort(B);
            
            for (int i = 0; i < A.length; i++) {
                // 배열 A는 순서대로, 배열 B는 역순으로 접근하여 곱하여 answer에 더함
                answer += A[i] * B[B.length - i - 1];
            }
            
            return answer;
        }
    }
