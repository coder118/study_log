# 문제 정의

정수 n을 연속된 자연수들의 합으로 나타낼 수 있는 방법의 수를 구하는 문제다.

1. for 문을 통해 i부터 n까지 1씩 증가시키면서 반복한다. 반복문 내에서 연속된 자연수의 합을 저장하기 위한 변수 sum을 초기화한다.
2. 중첩 for 문에서 현재 i를 시작(j = i)으로 n까지 1씩 증가시키면서 sum에 더한다.
3. sum이 n과 같으면 answer를 1 증가시키고 중첩 for 문을 종료하여 다음 i부터 다시 시작한다.
4. 만약, sum이 n보다 커지면 중첩 for 문을 종료하여 다음 i부터 다시 시작한다.
5. 모든 반복문이 종료되면 answer를 반환한다.


# 코드


    class Solution {
        public int solution(int n) {
            int answer = 0;
            
            for (int i = 1; i <= n; i++) {
                int sum = 0;
                
                // 현재 i부터 n까지 자연수를 더해가면서 합을 계산
                for (int j = i; j <= n; j++) {
                    sum += j;
                    
                    // 현재 i부터 n까지 자연수를 더해가면서 합을 계산
                    if (sum == n) {
                        answer++;
                        break;
                    }
                    
                    // 합이 주어진 n보다 크면 내부 반복문 종료
                    if (sum > n) break;
                }
            }

            return answer;
        }
    }
