

# 문제 정의


### 제약 조건 분석

* 값의 범위가 최대 1,000,000이므로 O(Y) 시간 복잡도 내에 해결 필요

---

### 패턴 단순화 및 추상화

* 최단 거리 및 최소 연산 횟수를 구하는 문제이므로 너비 우선 탐색 또는 동적 계획법 적용
* x에서 y로 커지는 방향 대신 y에서 x로 줄어드는 역방향 DP 적용 가능
* i라는 수에 도달하기 위한 최소 연산 횟수를 DP 배열에 저장
* i에서 n을 뺀 값, 2로 나눈 값, 3으로 나눈 값 중 최솟값으로 갱신

---

### 경계 조건

* x와 y가 처음부터 같은 경우 연산이 필요 없으므로 0 반환
* 2 또는 3으로 나누어 떨어지지 않는 수인 경우 해당 나누기 연산 제외
* 연산 결과가 x보다 작아지는 경우 해당 경로 탐색 제외

---

### 최적의 알고리즘

1. y + 1 크기의 DP 배열을 생성 후 큰 값으로 초기화 진행
2. DP 배열의 x 인덱스 위치에 0 저장
3. x + 1부터 y까지 순회하며 최소 연산 횟수 계산
4. i 마이너스 n이 x 이상이면 이전 연산 횟수 + 1 적용
5. i가 2로 나누어 떨어지고 나누기 2 결과가 x 이상이면 기존 값과 비교하여 최솟값 갱신
6. i가 3으로 나누어 떨어지고 나누기 3 결과가 x 이상이면 기존 값과 비교하여 최솟값 갱신
7. 최종 DP 배열의 y 인덱스 값 반환하며 만약 초기 상태 유지 시 -1 반환

---

# 코드

    import java.util.Arrays;

    class Solution {
        public int solution(int x, int y, int n) {
            if (x == y) {
                return 0;
            }

            int[] dp = new int[y + 1];
            Arrays.fill(dp, 1000001);
            dp[x] = 0;

            for (int i = x + 1; i <= y; i++) {
                if (i - n >= x) {
                    dp[i] = Math.min(dp[i], dp[i - n] + 1);
                }
                if (i % 2 == 0 && i / 2 >= x) {
                    dp[i] = Math.min(dp[i], dp[i / 2] + 1);
                }
                if (i % 3 == 0 && i / 3 >= x) {
                    dp[i] = Math.min(dp[i], dp[i / 3] + 1);
                }
            }

            return dp[y] == 1000001 ? -1 : dp[y];
        }
    }
