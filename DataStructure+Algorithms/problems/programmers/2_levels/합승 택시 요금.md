# 문제 정의

### 제약 조건 분석

* 지점의 개수는 3 이상 200 이하의 자연수로 구성
* 출발 지점과 각 도착 지점은 1 이상 n 이하의 자연수이며 서로 중복되지 않음
* 두 지점 사이의 택시요금 정보는 중복 없이 단 하나만 제공
* 출발지에서 각 목적지로 이동 가능한 경로만 입력으로 주어짐

---

### 패턴 단순화 및 추상화

* 출발점에서 특정 환승 지점까지는 두 사람이 합승하여 이동하는 구조
* 환승 지점에서 각자의 목적지까지는 각각 개별적으로 이동하는 구조
* 합승을 전혀 하지 않고 출발점에서 각자 목적지로 직행하는 경우도 환승 지점이 출발점인 특수 상황으로 통합하여 처리 가능
* 임의의 지점 k를 환승 지점으로 설정했을 때의 총 비용은 출발점에서 k까지의 최단 거리와 k에서 각 목적지까지의 최단 거리의 합으로 표현

---

### 경계 조건

* 합승을 전혀 하지 않고 각자 이동하는 비용이 합승하는 비용보다 작은 경우를 고려
* 출발점 자체가 환승 지점이 되는 경우를 확인
* 특정 목적지가 환승 지점이 되어 한 사람은 내리고 다른 한 사람만 남은 목적지로 이동하는 경우를 확인
* 지점 간 연결이 되지 않아 접근이 불가능한 경로는 최단 거리 계산 시 무한대 값으로 처리하여 제외

---

### 최적의 알고리즘

1. 플로이드 워셜 알고리즘이나 다익스트라 알고리즘을 활용하여 모든 지점 간의 최단 거리를 계산
2. 모든 지점 k를 순회하며 출발점에서 k까지의 최단 거리, k에서 A의 목적지까지의 최단 거리, k에서 B의 목적지까지의 최단 거리를 합산한 총 비용을 산출.
3. 계산된 총 비용들 중 최솟값을 탐색하여 최종 택시 요금으로 결정하는 과정을 진행.

# 코드


    import java.util.Arrays;

    class Solution {
        public int solution(int n, int s, int a, int b, int[][] fares) {
            int INF = 20000000;
            int[][] dist = new int[n + 1][n + 1];

            for (int i = 1; i <= n; i++) {
                Arrays.fill(dist[i], INF);
                dist[i][i] = 0;
            }

            for (int[] fare : fares) {
                int u = fare[0];
                int v = fare[1];
                int cost = fare[2];
                dist[u][v] = cost;
                dist[v][u] = cost;
            }

            for (int k = 1; k <= n; k++) {
                for (int i = 1; i <= n; i++) {
                    for (int j = 1; j <= n; j++) {
                        if (dist[i][j] > dist[i][k] + dist[k][j]) {
                            dist[i][j] = dist[i][k] + dist[k][j];
                        }
                    }
                }
            }

            int minCost = INF;

            for (int k = 1; k <= n; k++) {
                int cost = dist[s][k] + dist[k][a] + dist[k][b];
                minCost = Math.min(minCost, cost);
            }

            return minCost;
        }
    }
