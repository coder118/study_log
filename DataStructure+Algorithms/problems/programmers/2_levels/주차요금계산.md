# 문제 정의
---

### 제약 조건 분석

* 입출차 기록 배열의 길이가 최대 1,000이므로 시간 복잡도는 O(N log N) 내 해결 필요
* 차량 번호 기준 오름차순 정렬이 필요하므로 정렬 기능 또는 정렬된 Map 자료구조 활용 필요

---

### 패턴 단순화 및 추상화

* 시각 문자열을 시 분 형태에서 전체 분 단위 정수로 변환하여 계산 단순화 진행
* 차량별 입차 시각을 관리하는 Map과 누적 주차 시간을 기록하는 Map 두 개를 활용
* 입차 기록 발생 시 시각을 기록하고 출차 기록 발생 시 입차 시각과의 차이를 누적 시간에 추가
* 정산 단계에서 출차 기록이 남은 차량은 23:59 출차 기준으로 차이를 누적 시간에 추가
* 차량 번호 오름차순으로 누적 시간을 정산 공식을 적용해 최종 요금 계산

---

### 경계 조건

* 누적 주차 시간이 기본 시간 이하인 경우 추가 요금 없이 기본 요금 적용
* 초과 시간이 단위 시간으로 나누어떨어지지 않을 경우 올림 처리 적용
* 하루 동안의 기록만 주어지며 당일 23:59를 넘기는 입출차는 존재하지 않음

---

### 최적의 알고리즘

1. 차량별 입차 시각을 저장할 Map과 누적 주차 시간을 저장할 Map 생성 진행
2. 입출차 기록 배열을 순회하며 시각을 분 단위 정수로 변환 진행
3. 내역이 입차인 경우 입차 Map에 차량 번호와 시각 저장
4. 내역이 출차인 경우 입차 Map에서 시각을 꺼내 차이를 구한 뒤 누적 시간 Map에 합산 기록
5. 순회 종료 후 입차 Map에 남아있는 차량은 23:59 출차 기준으로 차이를 구해 누적 시간 Map에 합산 기록
6. 누적 시간 Map의 Key를 오름차순 정렬하여 순회 진행
7. 기본 시간 초과 여부에 따라 기본 요금 및 올림 계산을 적용한 단위 요금을 합산하여 결과 배열에 추가 및 반환

# 코드

    import java.util.*;

    class Solution {
        public int[] solution(int[] fees, String[] records) {
            int baseTime = fees[0];
            int baseFee = fees[1];
            int unitTime = fees[2];
            int unitFee = fees[3];

            Map<String, Integer> inTimeMap = new HashMap<>();
            Map<String, Integer> totalTimeMap = new TreeMap<>();

            for (String record : records) {
                String[] parts = record.split(" ");
                String[] timeParts = parts[0].split(":");
                int time = Integer.parseInt(timeParts[0]) * 60 + Integer.parseInt(timeParts[1]);
                String carNumber = parts[1];
                String type = parts[2];

                if (type.equals("IN")) {
                    inTimeMap.put(carNumber, time);
                } else {
                    int inTime = inTimeMap.remove(carNumber);
                    totalTimeMap.put(carNumber, totalTimeMap.getOrDefault(carNumber, 0) + (time - inTime));
                }
            }

            int maxTime = 23 * 60 + 59;
            for (String carNumber : inTimeMap.keySet()) {
                int inTime = inTimeMap.get(carNumber);
                totalTimeMap.put(carNumber, totalTimeMap.getOrDefault(carNumber, 0) + (maxTime - inTime));
            }

            int[] answer = new int[totalTimeMap.size()];
            int idx = 0;

            for (int totalTime : totalTimeMap.values()) {
                if (totalTime <= baseTime) {
                    answer[idx++] = baseFee;
                } else {
                    int extraTime = totalTime - baseTime;
                    int extraFee = (int) Math.ceil((double) extraTime / unitTime) * unitFee;
                    answer[idx++] = baseFee + extraFee;
                }
            }

            return answer;
        }
    }
