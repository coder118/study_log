# 문제 정의

1. 먼저 형, 동생을 위한 각각의 Map을 선언한다.
2. 이때, 동생의 Map은 전체 배열을 넣어주고, 형의 Map은 빈 Map으로 설정한다.
3. 각각의 원소를 돌면서 각 원소에 대하여, 형의 경우에는 원소를 더해주고, 동생의 경우에는 원소를 빼준다. 
4. 그러면서, 동생과 형의 Map크기를 비교하여 크기가 같으면, Key 즉, 가지고 있는 토핑의 가짓수가 같음을 의미하므로 answer를 더해준다.


# 코드


    import java.util.*;
    class Solution {
        public int solution(int[] topping) {
            int answer = 0;
            
            Map<Integer, Integer> map_1 = new HashMap<>(); // 형
            Map<Integer, Integer> map_2 = new HashMap<>(); // 동생
            
            for (int e : topping) {
                map_2.put(e, map_2.getOrDefault(e, 0) + 1);
            }
            
            for (int e : topping) {
                map_1.put(e, map_1.getOrDefault(e, 0) + 1);
                
                if (map_2.get(e) - 1 == 0)
                    map_2.remove(e);
                else
                    map_2.put(e, map_2.get(e) - 1);  
                
                if (map_1.size() == map_2.size())
                    answer++;
            }

            return answer;
        }
    }
