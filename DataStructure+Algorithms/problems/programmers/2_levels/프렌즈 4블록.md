# 문제 정의


### 제약 조건 분석

* 블록을 나타내는 문자는 대문자 에이부터 제트까지 사용.
* 같은 블록은 여러 이곱하기 이 형태에 중복으로 포함될 수 있으며 조건이 맞춰지면 한꺼번에 지움.

---

### 패턴 단순화 및 추상화

* 전체 판에서 이곱하기 이 형태를 이루는 동일한 캐릭터 블록 위치를 탐색.
* 조건에 맞는 블록들을 지울 대상으로 지정하고 일괄 제거 처리.
* 블록이 지워진 빈 공간으로 위에 위치한 블록들이 아래로 떨어지는 동작을 구현.
* 더 이상 지울 수 있는 이곱하기 이 블록이 나타나지 않을 때까지 과정을 반복.

---

### 경계 조건

* 블록이 아래로 떨어질 때 빈 공간을 정확히 메우도록 배열을 재배치.
* 지워진 블록의 위치를 중복으로 세지 않고 정확한 제거 개수를 누적.
* 더 이상 지워지는 블록이 없을 때 반복을 종료.

---

### 최적의 알고리즘

1. 입력받은 문자열 배열을 수정하기 편하도록 이차원 문자 배열로 변환.
2. 전체 판을 순회하며 이곱하기 이 영역의 블록이 모두 같은지 확인.
3. 지워야 할 블록의 위치를 별도의 이차원 불리언 배열에 표시.
4. 표시된 위치의 블록을 빈 공간으로 변경하고 지워진 개수를 더함.
5. 각 열별로 아래에서부터 빈 공간을 찾아 위에 있는 블록을 떨어뜨림.
6. 지워진 블록이 없으면 반복을 멈추고 총 지워진 블록 개수를 반환.

---

# 코드

    class Solution {
        public int solution(int m, int n, String[] board) {
            char[][] map = new char[m][n];
            for (int i = 0; i < m; i++) {
                map[i] = board[i].toCharArray();
            }

            int totalRemoved = 0;

            while (true) {
                boolean[][] marked = new boolean[m][n];
                boolean hasRemoved = false;

                for (int i = 0; i < m - 1; i++) {
                    for (int j = 0; j < n - 1; j++) {
                        char current = map[i][j];
                        if (current == '.') {
                            continue;
                        }

                        if (current == map[i][j + 1] && current == map[i + 1][j] && current == map[i + 1][j + 1]) {
                            marked[i][j] = true;
                            marked[i][j + 1] = true;
                            marked[i + 1][j] = true;
                            marked[i + 1][j + 1] = true;
                            hasRemoved = true;
                        }
                    }
                }

                if (!hasRemoved) {
                    break;
                }

                for (int i = 0; i < m; i++) {
                    for (int j = 0; j < n; j++) {
                        if (marked[i][j]) {
                            totalRemoved++;
                            map[i][j] = '.';
                        }
                    }
                }

                for (int j = 0; j < n; j++) {
                    for (int i = m - 1; i >= 0; i--) {
                        if (map[i][j] == '.') {
                            for (int k = i - 1; k >= 0; k--) {
                                if (map[k][j] != '.') {
                                    map[i][j] = map[k][j];
                                    map[k][j] = '.';
                                    break;
                                }
                            }
                        }
                    }
                }
            }

            return totalRemoved;
        }
    }
