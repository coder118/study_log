# 문제 정의

### 제약 조건 분석

이는 시간 복잡도 O(N^3)으로도 아주 여유 있게 통과할 수 있는 크기

---

### 패턴 단순화 및 추상화

* 행렬 곱셈 정의: 결과 행렬의 (i, j) 위치 원소는 arr1의 i번째 행과 arr2의 j번째 열의 내적 합이다.
* 차원 크기 정의: arr1의 행 크기를 r1, arr1의 열 크이자 arr2의 행 크기를 c1, arr2의 열 크기를 c2라 할 때 결과 행렬의 크기는 r1 x c2가 된다
* 값 축적 방식: 결과 행렬의 각 셀에 대해 arr1의 행 원소와 arr2의 열 원소를 순서대로 곱해 모두 더한다

---

### 경계 조건

* 행렬의 크기가 정방행렬이 아닐 수 있으며 arr1의 열 길이와 arr2의 행 길이가 일치하는 올바른 입력을 기준으로 처리.
* 원소의 값이 음수(-10 이상)일 수 있으므로 곱셈 시 음수 연산 처리가 정확해야 한다.
* 결과 배열의 행과 열 개수를 초기화할 때 arr1.length와 arr2[0].length를 정확히 지정해야 한다.

---

### 최적의 알고리즘

1. arr1의 행 개수 r1, 열 개수 c1, arr2의 열 개수 c2를 구한다.
2. 크기가 r1 x c2인 2차원 배열 answer를 생성한다
3. i는 0부터 r1 미만까지, j는 0부터 c2 미만까지, k는 0부터 c1 미만까지 돌며 3중 반복문을 구성한다.
4. answer[i][j]에 arr1[i][k]와 arr2[k][j]의 곱을 누적하여 더한다.
5. 계산이 완료된 2차원 배열 answer를 반환한다.


# 코드

    class Solution {
        public int[][] solution(int[][] arr1, int[][] arr2) {
            int r1 = arr1.length;
            int c1 = arr1[0].length;
            int c2 = arr2[0].length;
            
            int[][] answer = new int[r1][c2];
            
            for (int i = 0; i < r1; i++) {
                for (int j = 0; j < c2; j++) {
                    for (int k = 0; k < c1; k++) {
                        answer[i][j] += arr1[i][k] * arr2[k][j];
                    }
                }
            }
            
            return answer;
        }
    }
