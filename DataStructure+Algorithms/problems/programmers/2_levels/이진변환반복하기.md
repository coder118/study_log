# 문제 정의

 문자열 s가 "1"이 될 때까지 반복하여 0을 제거하고, 남은 1의 길이를 2진수로 변환하는 작업을 하여 변환 횟수와 제거한 0의 개수를 반환하는 문제다.


# 코드


    class Solution {
        public int[] solution(String s) {
            int[] answer = new int[2];
            
            // 문자열 s의 길이가 1이 될 때까지 반복
            while (s.length() > 1) {
                // 1의 개수를 담을 변수
                int one = 0;

                // 문자열 s 순회
                for (int i = 0; i < s.length(); i++) {

                    // 현재 문자가 '0'이면 answer[1] 증가
                    if (s.charAt(i) == '0') {
                        answer[1]++;
                    // 현재 문자가 '0'이 아니면 one 증가
                    } else {
                        one++;
                    }
                }

                // one을 2진수로 변환 후 s에 저장
                s = Integer.toBinaryString(one);
                // 반복 횟수 answer[0] 증가
                answer[0]++;
            }
            
            return answer;
        }
    }

1. 결과를 반환하기 위해 길이가 2인 answer 배열을 선언한다. answer[0]에는 2진수로 변환한 횟수, answer[1]에는 제거한 0의 개수를 담을 것이다.
2. while 문을 통해 s의 길이가 1이 될 때까지 반복한다.(s가 "1"이 될 때까지)
3. 1의 개수를 담을 변수 one을 선언하고, 문자열 s를 순회한다.
4. 반복문에서 현재 문자가 '0'이면 제거 대상으로 answer[1]을 증가시키고, '0'이 아니면 변수 one을 증가시킨다.
5. 반복문이 종료되면 one을 Integer.toBinaryString() 메서드를 통해 2진수로 변환하고 answer[0]을 1 증가시킨다.
