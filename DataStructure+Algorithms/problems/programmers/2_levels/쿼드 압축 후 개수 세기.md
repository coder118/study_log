# 문제 정의

### 제약 조건 분석

* 각 행의 길이는 행의 개수와 같으며 모든 요소는 0 또는 1로 구성

---

### 패턴 단순화 및 추상화

* 현재 영역의 모든 요소가 동일한지 검사하는 확인 단계 수행
* 모든 요소가 같으면 해당하는 숫자의 개수를 1 증가시키고 탐색 종료
* 하나라도 다르면 영역을 4개의 분할 영역으로 쪼개서 각각 재귀 호출 진행

---

### 경계 조건

* 영역의 크기가 1까지 줄어들면 더 이상 쪼갤 수 없으므로 해당 값 개수 증가
* 영역 내부의 모든 값이 0 또는 1로 완전히 일치하는 경우 즉시 압축 성공
* 분할된 4개의 영역이 각각 독립적으로 재귀 과정을 마치는지 확인

---

### 최적의 알고리즘

1. 시작 좌표와 영역의 크기를 매개변수로 갖는 재귀 탐색 함수 정의
2. 현재 영역 내부의 모든 값이 같은지 확인하는 검사 함수 실행
3. 모두 동일하다면 해당 숫자의 카운트를 1 증가시키고 함수 종료
4. 하나라도 다르면 영역 크기를 반으로 줄여 4개의 사분면 영역에 대해 재귀 함수 호출
5. 전체 영역 탐색이 끝난 후 0의 개수와 1의 개수를 순서대로 배열에 담아 반환

# 코드

    class Solution {
        private int zeroCount = 0;
        private int oneCount = 0;

        public int[] solution(int[][] arr) {
            compress(arr, 0, 0, arr.length);
            return new int[]{zeroCount, oneCount};
        }

        private void compress(int[][] arr, int row, int col, int size) {
            if (isSame(arr, row, col, size)) {
                if (arr[row][col] == 0) {
                    zeroCount++;
                } else {
                    oneCount++;
                }
                return;
            }

            int newSize = size / 2;
            compress(arr, row, col, newSize);
            compress(arr, row, col + newSize, newSize);
            compress(arr, row + newSize, col, newSize);
            compress(arr, row + newSize, col + newSize, newSize);
        }

        private boolean isSame(int[][] arr, int row, int col, int size) {
            int value = arr[row][col];
            for (int i = row; i < row + size; i++) {
                for (int j = col; j < col + size; j++) {
                    if (arr[i][j] != value) {
                        return false;
                    }
                }
            }
            return true;
        }
    }
