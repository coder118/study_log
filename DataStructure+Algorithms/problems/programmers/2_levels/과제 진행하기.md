# 문제 정의하기

### 제약 조건 분석

- 과제 개수(N): 3 이상 1000 이하로 매우 적어서 O(N log N) 알고리즘으로 충분히 해결 가능
---

### 패턴 단순화 및 추상화

- 시간 단위를 분으로 통일: 시 * 60 + 분 형태로 변환
- 스택 구조 활용: '가장 최근에 멈춘 과제부터 다시 시작한다'는 조건은 후입선출 특성 = 스택
- 시간 순 정렬: 시작 시각 기준 오름차순으로 우선 정렬

---

### 경계 조건

- 과제 종료와 동시에 새 과제 시작
- 남는 시간 발생: 현재 과제를 완료하고 다음 과제 시작 시각까지 여유 시간이 남는 경우, 스택에 남아 있는 멈춰둔 과제들을 가장 최근 것부터 차례대로 꺼내어 남는 시간만큼 진행.
- 모든 새로운 과제 착수 완료 후: 더 이상 새로 시작할 과제가 남아있지 않다면, 스택에 멈춰있는 과제들을 최근에 멈춘 순서대로 끝까지 순차 처리.

---

### 최적의 알고리즘

1. 데이터 전처리 및 정렬
   - 입력된 plans의 시작 시각("hh:mm")을 분 단위 정수로 변환
   - 과제들을 시작 시각 기준 오름차순으로 정렬

2. 과제 진행 및 스택 관리
   - 정렬된 과제 목록을 순회하며 현재 과제와 '다음 시작할 과제' 사이의 시간 간격을 계산
   - Case 1 시간 부족: playtime > time_gap
     - 현재 과제를 time_gap만큼만 진행하고, 잔여 시간을 갱신하여 스택에 push
   - Case 2 시간 딱 맞음: playtime == time_gap
     - 현재 과제를 완료 목록에 추가
   - Case 3 시간 남음: playtime < time_gap
     - 현재 과제를 완료 목록에 추가하고, 남은 시간 동안 스택에서 멈춘 과제들을 pop하여 가능한 만큼 진행/완료 처리

3. 잔여 과제 일괄 처리
   - 모든 과제의 시작 시각 처리가 끝나면, 스택에 남아 있는 과제들을 하나씩 pop하며 완료 목록에 순서대로 담아 반환


# 코드

    import java.util.*;

    class Solution {
    
        static class Task {
            String name;
            int start;      // 분 단위 변환 시각
            int playtime;   // 남은 소요 시간

            Task(String name, int start, int playtime) {
                this.name = name;
                this.start = start;
                this.playtime = playtime;
            }
        }

        private int convertToMinutes(String timeStr) {
            String[] split = timeStr.split(":");
            int hour = Integer.parseInt(split[0]);
            int minute = Integer.parseInt(split[1]);
            return hour * 60 + minute;
        }

        public String[] solution(String[][] plans) {
            List<Task> tasks = new ArrayList<>();

            for (String[] plan : plans) {
                String name = plan[0];
                int start = convertToMinutes(plan[1]);
                int playtime = Integer.parseInt(plan[2]);
                tasks.add(new Task(name, start, playtime));
            }

            // 과제 시작 시각 기준 오름차순 정렬
            Collections.sort(tasks, (a, b) -> Integer.compare(a.start, b.start));

            List<String> answerList = new ArrayList<>();
            Stack<Task> stopStack = new Stack<>(); // 멈춰둔 과제를 보관할 스택

            // 2. 과제 진행 및 스택 관리
            for (int i = 0; i < tasks.size() - 1; i++) {
                Task current = tasks.get(i);
                Task next = tasks.get(i + 1);

                int timeGap = next.start - current.start; // 다음 과제 시작까지 남아있는 시간

                // 현재 과제를 완료하기에 시간이 부족한 경우
                if (current.playtime > timeGap) {
                    current.playtime -= timeGap;
                    stopStack.push(current);
                } 
                // 현재 과제가 딱 맞춰 끝나는 경우
                else if (current.playtime == timeGap) {
                    answerList.add(current.name);
                } 
                //현재 과제를 완료하고도 시간이 남는 경우
                else {
                    answerList.add(current.name);
                    int remainTime = timeGap - current.playtime;

                    // 스택에 멈춰둔 과제가 있고 남은 시간이 있다면 계속 꺼내어 진행
                    while (!stopStack.isEmpty() && remainTime > 0) {
                        Task stoppedTask = stopStack.peek();

                        if (stoppedTask.playtime <= remainTime) {
                            remainTime -= stoppedTask.playtime;
                            answerList.add(stopStack.pop().name);
                        } else {
                            stoppedTask.playtime -= remainTime;
                            remainTime = 0;
                        }
                    }
                }
            }

            // 마지막 과제는 무조건 완료 처리
            answerList.add(tasks.get(tasks.size() - 1).name);

            // 3. 잔여 과제 일괄 처리 
            while (!stopStack.isEmpty()) {
                answerList.add(stopStack.pop().name);
            }

            return answerList.toArray(new String[0]);
        }
    }
