# 문제 정의

### 제약 조건 분석

* 반지름의 크기가 백만까지 주어지므로 모든 좌표를 직접 완전탐색하면 시간 초과가 발생함을 확인
* 시간 복잡도를 줄이기 위해 일차원 반복문을 활용하는 효율적인 접근 방식 중심

---

### 패턴 단순화 및 추상화

* 사분면의 대칭성을 활용하여 일사분면의 점의 개수를 구한 뒤 네 배를 곱하는 방식으로 계산 구조를 단순화
* 가로 좌표를 기준으로 각 위치에서의 세로 좌표의 최소값과 최대값을 산출하는 수학적 추상화 과정 도출

---

### 경계 조건

* 작은 원의 내부에 위치하여 음수가 되는 제곱 연산 결과는 최대값 함수를 통해 영으로 보정하는 예외 처리 설정
* 원의 경계에 걸치는 정수 좌표를 포함하기 위해 올림과 내림 함수를 정확히 적용하는 조건 검증

---

### 알고리즘 설계

1. 일부터 큰 원의 반지름까지 반복문을 수행하여 각 가로 좌표를 순회하는 과정 설정
2. 피타고라스 정리를 응용하여 현재 가로 좌표에서 허용되는 세로 좌표의 최대값과 최소값을 각각 계산
3. 산출된 세로 좌표의 개수를 누적한 뒤 최종 결과값에 네 배를 곱하여 반환하는 판정 과정 완성

---

# 코드 

    class Solution {
        public long solution(long r1, long r2) {
            long answer = 0;
            for (long x = 1; x <= r2; x++) {
                long maxY = (long) Math.floor(Math.sqrt(r2 * r2 - x * x));
                long minY = (long) Math.ceil(Math.sqrt(Math.max(0, r1 * r1 - x * x)));
                answer += (maxY - minY + 1);
            }
            return answer * 4;
        }
    }
