# 문제 정의

### 제약 조건 분석

- 이모티콘의 개수는 최대 7개로 제한.
- 각 이모티콘에 적용할 수 있는 할인율은 10퍼센트, 20퍼센트, 30퍼센트, 40퍼센트의 4가지이다. 
- 전체 경우의 수는 4의 7제곱인 16384가지 -> 완탐 가능
---

### 패턴 단순화 및 추상화

* 전체 조합 탐색: 각 이모티콘마다 4가지 할인율 중 하나를 선택하는 모든 경우를 생성.
* 사용자별 계산: 각 사용자 기준에 따라 특정 할인율 이상인 이모티콘의 구매 금액을 합산.
* 서비스 가입 및 매출 판정: 구매 합산 금액이 사용자의 지정 가격 이상이면 이모티콘 구매를 취소하고 플러스 서비스에 가입 처리하며, 지정 가격 미만이면 해당 금액을 매출액에 반영.

---

### 경계 조건

* 가입자 수 우선: 가입자 수를 늘리는 것이 최우선 목표이며, 가입자 수가 같은 경우에만 매출액이 큰 경우로 정답을 갱신.
* 할인율 조건: 사용자가 설정한 비율 이상인 이모티콘만 구매 대상에 포함.
* 금액 정수형 처리: 모든 가격과 매출액 계산은 정수 범위 내에서 처리할 수 있다.

---

### 최적의 알고리즘

1. 이모티콘 할인율 조합을 생성하는 백트래킹 또는 완전 탐색 함수 정의.
2. 현재 할인율 조합에 대해 각 사용자별 구매 금액 계산 및 플러스 서비스 가입 여부 확인.
3. 서비스 가입자 수 최대화 및 매출액 최대화 조건에 맞춰 정답 갱신 연산 수행.
4. 탐색이 종료된 후 최종 가입자 수와 매출액을 담은 배열 반환.

---

    class Solution {
        
        int maxSubscribers = 0;
        int maxSales = 0;
        int[] discountRates = {10, 20, 30, 40};

        public int[] solution(int[][] users, int[] emoticons) {
            int[] currentDiscounts = new int[emoticons.length];
            findBestDiscount(0, currentDiscounts, users, emoticons);
            
            int[] answer = new int[2];
            answer[0] = maxSubscribers;
            answer[1] = maxSales;
            return answer;
        }

        private void findBestDiscount(int index, int[] currentDiscounts, int[][] users, int[] emoticons) {
            if (index == emoticons.length) {
                calculateResult(currentDiscounts, users, emoticons);
                return;
            }

            for (int i = 0; i < 4; i++) {
                currentDiscounts[index] = discountRates[i];
                findBestDiscount(index + 1, currentDiscounts, users, emoticons);
            }
        }

        private void calculateResult(int[] currentDiscounts, int[][] users, int[] emoticons) {
            int currentSubscribers = 0;
            int currentSales = 0;

            for (int i = 0; i < users.length; i++) {
                int requiredDiscount = users[i][0];
                int limitPrice = users[i][1];
                int userSpent = 0;

                for (int j = 0; j < emoticons.length; j++) {
                    if (currentDiscounts[j] >= requiredDiscount) {
                        userSpent += emoticons[j] * (100 - currentDiscounts[j]) / 100;
                    }
                }

                if (userSpent >= limitPrice) {
                    currentSubscribers++;
                } else {
                    currentSales += userSpent;
                }
            }

            if (currentSubscribers > maxSubscribers) {
                maxSubscribers = currentSubscribers;
                maxSales = currentSales;
            } else if (currentSubscribers == maxSubscribers) {
                if (currentSales > maxSales) {
                    maxSales = currentSales;
                }
            }
        }
    }
