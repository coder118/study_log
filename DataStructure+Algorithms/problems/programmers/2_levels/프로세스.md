# 문제 정의


1. 프로세스를 우선순위에 따라 다루기 위해 우선순위 큐를 선언.
2. 내부에는 for문을 선언하여 priorities를 순차적으로 탐색. 
3. 현재 큐 제일 앞에 위치한 우선순위와 priorities에 담긴 우선순위를 비교하고, 일치하는게 있다면 poll()을 통해 제거해주고 answer을 증가.
4. 이 과정을 반복하여 원하는 위치의 원소를 찾으면 return해줍니다.


# 코드

    //PriorityQueue를 이용한 풀이
    import java.util.*;

    class Solution {
        public int solution(int[] priorities, int location) {
            int answer = 0;
            PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
            
            for(int num : priorities) {
                pq.add(num);
            }
            while(!pq.isEmpty()) {
                for(int i=0; i<priorities.length; i++) {
                    if(priorities[i] == pq.peek()) {
                        pq.poll();
                        answer++;
                        if(i == location)
                            return answer;
                    }
                }
            }  
            return answer;
        }
    }
