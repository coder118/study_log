# 문제 정의

1. 처음 queue에 넣는 {0,0,1} 값: 0번째와 1번째 Index는 현재 검색 중인 x, y 좌표를, 2번째 Index는 cnt(현재까지 걸어온 거리)를 나타낸다.

2. visited 배열: 해당 좌표를 이미 방문했는지 체크. 처음에 (0,0)을 방문했으니, visited[0][0]을 true로 설정
3. queue가 비어있지 않을 때까지 while문을 반복. (BFS)
4. 현재 좌표가 상대편 진영 (n-1, m-1)이라면 cnt(최단 거리)를 return 한다.
5. 순차적인 동서남북 탐색을 위해 For문을 이용하여 x와 y값에 dx, dy의 현재 배열값을 더하고 해당 nx, ny값이 0보다 크고 n, m보다 작으면서 maps[n][m]이 1(갈 수 있는 곳)이면서 visited 하지 않은 곳이라면,
6. 다음에 탐색할 좌표의 visited를 true로 변경하고 queue에 추가. 
7. 이때 cnt는 1 증가시켜, 현재까지 걸어온 거리를 업데이트.


# 코드

    import java.util.*;

    class Solution {
        private static final int[] dx = {0, 0, -1, 1};
        private static final int[] dy = {-1, 1, 0, 0};
        
        public int solution(int[][] maps) {
            int n = maps.length;
            int m = maps[0].length;
            
            boolean[][] visited = new boolean[n][m];
            Queue<int[]> queue = new LinkedList<>();
            queue.add(new int[]{0, 0, 1});
            visited[0][0] = true;
            
            while(!queue.isEmpty()){ // bfs
                int[] current = queue.poll();
                int x = current[0];
                int y = current[1];
                int cnt = current[2];
                
                if(x == n-1 && y == m-1){
                    return cnt; // 최단 거리 반환 (bfs: 가장 처음 return 되는게 최단 거리)
                }
                
                for(int i=0;i<4;i++){
                    int nx = x + dx[i];
                    int ny = y + dy[i];
                    
                    if(nx >=0 && ny >= 0 && nx < n && ny < m && maps[nx][ny] == 1 && !visited[nx][ny]){
                        visited[nx][ny] = true;
                        queue.add(new int[]{nx, ny, cnt+1});
                    }
                }
            }
            
            return -1;
        }
    }
