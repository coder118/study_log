# 문제 정의


### 제약 조건 분석

시간 복잡도 목표: N의 제곱

모든 경로를 직접 탐색하면 경로 수가 너무 많아 시간 초과가 발생하므로, 동적 계획법으로 해결해야 함

### 패턴 단순화 및 추상화

삼각형의 꼭대기에서 바닥까지 내려가며 거쳐간 숫자의 합 중 최댓값을 구함
이동 규칙: i번째 행의 j번째 위치에서는 바로 아래 또는 오른쪽 아래로만 이동 가능함

- 역방향 추상화 (바닥에서 위로):
바닥(맨 아래 행)에서부터 위로 올라가며 각 위치에서 얻을 수 있는 최대 합을 계산함
현재 위치의 최대 합 = 현재 값 + max(아래쪽 합, 오른쪽 아래쪽 합)

### 경계 조건
맨 아래 행: 맨 아래 행의 값들은 자기 자신이 최댓값이 됨

양 끝 경계: 아래에서부터 위로 올라가는 방식을 사용하면 양 끝 점에 대한 별도의 예외 처리 없이 자연스럽게 최댓값을 계산할 수 있음

### 최적의 알고리즘 (동적 계획법)
1. 삼각형 배열의 맨 아래 행 직전 행부터 맨 위 행까지 역순으로 반복문을 실행함

2. 각 위치마다 바로 아래 두 값 중 더 큰 값을 현재 위치의 값에 더함

3. 모든 연산이 끝나면 맨 꼭대기 위치에 바닥까지의 최댓값이 담기므로 해당 값을 반환함


# 코드

    class Solution {
        public int solution(int[][] triangle) {
            // 삼각형의 높이
            int n = triangle.length;
            
            // 바닥에서부터 위로 올라가며 최댓값 계산
            for (int i = n - 2; i >= 0; i--) {
                for (int j = 0; j < triangle[i].length; j++) {
                    // 바로 아래와 오른쪽 아래 중 더 큰 값을 현재 위치에 더함
                    triangle[i][j] += Math.max(triangle[i + 1][j], triangle[i + 1][j + 1]);
                }
            }
            
            return triangle[0][0];
        }
    }
