# 문제 정의


### 제약 조건 분석

* 문자열 s의 길이는 100,000 이하의 자연수
* 문자열 s는 여는 괄호와 닫는 괄호로만 구성
---

### 패턴 단순화 및 추상화

* 여는 괄호가 나오면 닫혀야 할 괄호의 개수를 1 증가
* 닫는 괄호가 나오면 대기 중인 여는 괄호의 개수를 1 감소
* 문자열 탐색 도중 닫는 괄호가 더 많이 나오면 즉시 올바르지 않은 괄호로 결정
* 문자열 탐색이 끝난 후 남아있는 여는 괄호가 없어야 올바른 괄호로 결정

---

### 경계 조건

* 닫는 괄호로 시작하는 문자열 입력 상황 확인
* 여는 괄호와 닫는 괄호의 총개수가 불일치하는 상황 확인
* 여는 괄호만 연속으로 입력되는 상황 확인

---

### 최적의 알고리즘

1. 여는 괄호의 개수를 카운트할 정수형 변수를 0으로 초기화
2. 입력 문자열의 각 문자를 순차적으로 순회하며 확인
3. 여는 괄호를 만나면 카운트를 1 증가시키고 닫는 괄호를 만나면 카운트를 1 감소
4. 카운트가 0보다 작아지면 여는 괄호보다 닫는 괄호가 먼저 나온 것이므로 거짓 반환
5. 모든 문자 순회가 끝난 후 카운트가 0이면 참을 반환하고 0이 아니면 거짓 반환

# 코드

    class Solution {
        boolean solution(String s) {
            int count = 0;

            for (int i = 0; i < s.length(); i++) {
                char c = s.charAt(i);

                if (c == '(') {
                    count++;
                } else {
                    count--;
                }

                if (count < 0) {
                    return false;
                }
            }

            return count == 0;
        }
    }
