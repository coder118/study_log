# 문제 정의

---

### 제약 조건 분석

* 변수의 크기가 매우 크게 주어지므로 전체 배열 생성이 불가능함을 확인
* 추출 구간의 길이는 제한되어 있으므로 부분 순회가 가능함을 확인

---

### 패턴 단순화 및 추상화

* 이차원 좌표에서 행과 열 중 큰 값에 일을 더한 값이 해당 위치의 데이터가 됨을 확인
* 일차원 인덱스를 엔으로 나눈 몫이 행이 되고 나머지가 열이 되는 규칙을 적용하여 완성
* 전체 배열을 만들지 않고 필요한 구간의 인덱스만 직접 계    산하여 메모리 절약 완성

---

### 경계 조건

* 시작 인덱스부터 끝 인덱스까지의 범위를 정확하게 반복하도록 설정하여 확인
* 입력값이 매우 클 수 있으므로 큰 자료형을 사용하여 오류 방지 확인

---

### 최적의 알고리즘

1. 구간의 크기만큼 결과 배열을 미리 생성하여 준비 완성
2. 시작 지점부터 끝 지점까지 반복문을 돌며 각 일차원 인덱스 계산 확인
3. 인덱스를 이용해 행과 열 번호를 각각 도출하여 반영 완성
4. 행과 열 중 큰 값에 숫자를 더한 결과를 배열에 저장하여 확인

---

# 코드

    class Solution {
        public int[] solution(int n, long left, long right) {
            int size = (int) (right - left + 1);
            int[] answer = new int[size];
            
            for (int i = 0; i < size; i++) {
                long index = left + i;
                int row = (int) (index / n);
                int col = (int) (index % n);
                answer[i] = (int) Math.max(row, col) + 1;
            }
            
            return answer;
        }
    }
